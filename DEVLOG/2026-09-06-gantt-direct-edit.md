# 간트 직접 편집과 계층 이동

## 사용 흐름

- 상세창 상단에서 제목·일정·진행률을 편집한다. 선택은 즉시, 글자·날짜는 입력 완료 후 저장한다. 오류·충돌은 입력을 보존하고 알린다.
- 수동 진행률을 숫자와 슬라이더로 조절하면 상세창과 차트가 함께 반응한다. 움직임 줄이기 설정을 존중한다.
- 모든 간트 선택창은 B flow의 공용 GlassDropdown을 사용한다.
- 왼쪽은 폴더 → 프로젝트 → 그룹 → 작업 트리다. 접기·선택·표시 전환·메뉴를 제공한다.
- 이름 행을 끌어 앞·뒤·그룹 안으로 옮긴다. 고스트와 드롭 위치 안내를 표시한다. 막대 날짜 이동과 빈 곳 화면 이동은 유지한다.
- 프로젝트 사이 이동은 양쪽을 한 번에 저장·복원한다. 공유 대상 증가와 끊기는 선행 연결을 확인하고, 확인 중 다른 변경이 오면 다시 시도하도록 한다.

## 구현 및 검증 순서

1. 상세 자동 저장 / 차트 포인터 / 데이터 이동을 독립 구현하고, 부모 작업에서 공용 선택창·트리·화면 연결을 담당한다.
2. 실패·연속 입력·대상 전환·계층 순서·원자 이동의 회귀를 먼저 재현하고 수정한다.
3. 기본 창 크기 프리뷰에서 로그인 후 전체 흐름을 직접 조작한다. 독립 로컬 심층 리뷰에서 발견한 문제를 수정한다.
4. typecheck·관련 테스트·전체 build:vite 후 PR, 로컬 리뷰, merge, 정확한 merge Windows build를 수행한다.
5. SQL은 로컬 트랜잭션·권한 검증과 독립 리뷰 후 적용한다. 배포 파일 전체 SHA-256 검증 뒤 manifest를 마지막에 게시한다.
