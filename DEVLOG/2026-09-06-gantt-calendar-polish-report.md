# 간트·캘린더 사용성 개선 보고서

작성일: 2026-09-06 · 대상: B flow v1.115.0 예정 · 비교 기준: v1.114.0

> **배포 전 검증 보고서입니다.** 실제 화면 확인, 독립 로컬 리뷰, 서버 색상 연동 검증을 마쳤습니다. 이 문서는 병합 전 검증 기록입니다. 이후 정식 빌드·배포의 최종 증거는 [PR #272](https://github.com/baehandoridori/Bflow-BGonly/pull/272)에 기록합니다.

이번 변경은 원하는 날짜를 찾기 쉽게 하고, 간트에서 만든 작업이 캘린더에서도 같은 색과 시간으로 보이도록 다듬는 데 초점을 맞췄습니다. 밝은 화면과 작은 창에서 읽기 어려웠던 글자, 메뉴와 상세창 배치도 함께 정리했습니다.

## 수정 전과 후

| 항목 | 수정 전 | 수정 후 |
|---|---|---|
| 날짜 탐색 | 다른 달을 보려면 차트를 직접 이동해야 했고, 현재 보고 있는 월과 주차를 빠르게 파악하기 어려웠습니다. | 이전 달·다음 달·오늘 이동 버튼을 추가했습니다. 화면에 보이는 월과 월요일 시작 주차를 표시하며, 연도가 바뀌는 주차도 구분합니다. |

| 마일스톤 | 시작과 끝이 같은 시각인 마일스톤이 시간표에서 한 시간짜리 일정처럼 보였고, 길이 조절 동작에 들어갈 수 있었습니다. | 한 시각과 작은 마커로 표시합니다. 끌어서 시각은 옮길 수 있지만 길이는 늘리지 않으며, 저장된 시작·종료 시각은 계속 같습니다. |
| 공용 선택 메뉴 | 일정 만들기·빠른 편집·상세창에 운영체제 기본 선택창과 앱 메뉴가 섞여 있었습니다. | 해당 화면의 선택창을 공용 메뉴로 맞췄습니다. 키보드 선택과 선택 후 포커스 복귀를 보강하고, 빠른 편집창에서 메뉴를 눌렀을 때 창이 먼저 닫히지 않도록 연결했습니다. |
| 툴팁 | 월간 일정 설명이 화면 위쪽이나 가장자리에서 잘리거나, 배경에 비해 흐리게 보일 수 있었습니다. | 공용 툴팁 색상을 적용하고 실제 크기에 맞춰 화면 안쪽에 배치합니다. 화면을 스크롤하거나 다른 곳을 누르거나 Escape를 누르면 설명을 닫습니다. |
| 라이트 모드 | 시간표에 어두운 배경 기준의 색이 남아 있었고, 주말·저장 결과·진행률·메뉴의 일부 글자가 흐렸습니다. | 화면 테마에 맞는 카드 배경과 글자색을 사용합니다. 주말, 선택 상태, 저장 성공·오류, 진행률의 대비를 조정했습니다. 일정 구분 색은 배경과 테두리에도 남깁니다. |
| 태그 필터와 일정 통계 | 밝은 색의 태그 글자와 투명한 일정 통계가 라이트 모드에서 흐렸습니다. | 태그의 구분 색·선택 동작은 유지하고 글자는 테마 기본 색으로 표시합니다. 일정 개수의 투명도도 제거했습니다. |
| 드래그 표시 테두리 | 달력 막대 갱신 때 테두리 설정끼리 충돌한다는 브라우저 경고가 있었습니다. | 고스트의 네 면을 각각 점선으로 지정해 일반 막대와 전환할 때 설정이 충돌하지 않도록 했습니다. |
| 작은 창과 상세창 | 차트의 고정 최소 높이와 상세창 간격 때문에 좁거나 낮은 창에서 작업 공간이 줄어들었습니다. | 차트가 남은 높이에 맞춰 줄어들도록 하고 상세창 간격을 정리했습니다. 상세창 상단의 닫기와 저장 상태 영역을 유지하도록 배치했습니다. 1280×720 및 1024×640 화면에서 확인했습니다. |

자동 저장, 완료 항목 보기, 삭제, 폴더 트리와 작업 끌어 이동은 앞선 버전에 도입된 기능입니다. 이번 버전의 신규 기능으로 다시 집계하지 않으며, 이번 수정과 충돌하지 않는지 함께 점검합니다. 완료는 기록을 남기는 상태 변경이고 삭제는 항목을 제거하는 동작이라는 구분도 유지합니다.

## OmniPlan의 기본 흐름과 비교

비교 범위는 작업을 구조화하고, 선택한 항목을 편집하고, 날짜를 탐색하는 기본 흐름입니다. OmniPlan의 전체 기능이나 세부 계산 방식을 동일하게 구현했다는 의미는 아닙니다.

| 기본 흐름 | 공식 문서에서 확인한 방식 | B flow의 현재 대응과 이번 조정 |
|---|---|---|
| 목록과 차트를 함께 사용 | 왼쪽 작업 목록에서 생성·편집·그룹화를 하고 오른쪽 차트에서 일정과 관계를 확인합니다. [Gantt View](https://support.omnigroup.com/documentation/omniplan/mac/4.5.5/en/gantt-view/) | 기존 계층 목록과 차트를 유지하면서 이름 열의 폭과 날짜 눈금 정렬을 조정했습니다. 폴더는 프로젝트를 정리하고, 프로젝트 안에서는 그룹으로 작업을 묶는 기존 구조를 사용합니다. |
| 선택한 작업의 상세 편집 | 선택한 작업의 정보, 일정, 선행 관계 등을 작업 상세창에서 다룹니다. [Task Inspector](https://support.omnigroup.com/documentation/omniplan/mac/4.5.5/en/the-task-inspector/) | 앞선 버전의 제목·기간·진행률 중심 자동 저장 흐름을 유지합니다. 이번에는 상세창의 간격, 저장 상태 가독성, 작은 높이에서의 배치를 다듬었습니다. |
| 차트에서 일정의 위치 파악 | 작업 막대와 관계를 시각적으로 확인하고 차트에서 편집합니다. [Gantt View](https://support.omnigroup.com/documentation/omniplan/mac/4.5.5/en/gantt-view/) | 기존 차트 이동·생성·편집 도구에 월 이동과 오늘 복귀, 주차 표시를 더했습니다. 추가된 버튼 구성은 B flow의 사용 흐름에 맞춘 선택입니다. |

### 확인 범위의 한계

- 실제 마우스 검증은 로컬 preview이고, 여러 운영 PC·실사용자 계정의 동시 조작과 이번 버전의 설치 후 실행은 별도 확인하지 않았습니다. 권한·동시 저장·롤백은 실제 SQL 및 자동 회귀 시험으로 확인했습니다.
- 툴팁 가장자리 배치는 순수 좌표 시험과 코드 리뷰로 확인했습니다. 모든 데이터·운영체제 배율·사용자 지정 강조색 조합을 전수 검사했다는 의미는 아닙니다.
- 운영 보안 진단은 적용 전후 58개로 동일하며 신규 지적 0개입니다(기존 INFO24/WARN31/ERROR3). 기존 다른 기능의 진단 항목을 이번 색상 변경의 해결 내역으로 포함하지 않습니다. [진단 설명](https://supabase.com/docs/guides/database/database-linter)

## 아직 구현하지 않은 개선 제안

아래 세 항목은 이번 완료 내역에 포함하지 않습니다.

| 우선순위 | 제안 | 이유와 필요한 결정 |
|---|---|---|
| 다음 사용성 정리 시 우선 | 하루 보기 이름과 오늘 이동 버튼 이름 구분 | 캘린더의 하루 보기 버튼도 ‘오늘’로 표시되어 실제 오늘로 이동하는 버튼과 혼동할 수 있습니다. 보기 이름을 ‘하루’, 이동 버튼을 ‘오늘로 이동’ 등으로 구분하는 문구 결정을 제안합니다. |
| 긴 프로젝트 사용 사례 확인 후 | ‘전체 맞춤’의 최소 배율 정책 정리 | 매우 긴 일정은 현재 최소 배율 때문에 한 화면에 전부 들어오지 않을 수 있습니다. 글자 가독성과 전체 기간 표시 중 어느 쪽을 우선할지 결정한 뒤 조정할 항목입니다. |
| 다른 화면을 다룰 때 | 다른 앱 페이지에 남은 운영체제 기본 선택창 정리 | 이번 범위의 캘린더 편집 메뉴는 교체했지만 다른 페이지에는 기본 선택창이 남아 있습니다. 각 화면의 키보드·팝업 동작을 확인하며 별도 범위로 다루는 것이 필요합니다. |

### 다른 화면에 남은 기본 선택창 목록

씬 목록, 리테이크 허브의 리비전 생성·추가, 에피소드 자료 보드, 플레이그라운드 관리·가격 차트, 활동 분석, 내 할일 위젯·상세창에서 기본 선택창을 확인했습니다. 위치 목록 확인과 이번 세 캘린더 편집 화면 교체를 구분하며, 해당 다른 화면의 전체 상호작용은 이번 인수 범위에 포함하지 않습니다.
