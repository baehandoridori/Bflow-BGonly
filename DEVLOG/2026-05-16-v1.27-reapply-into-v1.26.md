## 2. 충돌 해결 전략 — 외곽만 본 PR 패턴 유지, 내용은 v1.26 우선

v1.27.0 의 `<CommentPanelResizable>` 는 **외곽 wrapper** (motion.div 래퍼 + 드래그 핸들 + 너비 관리) 만 책임지고, 실제 댓글 콘텐츠는 props 로 받은 그대로 `<CommentPanel>` 에 넘긴다. 즉 v1.26 의 댓글 내부 기능 (이모지 / 이미지 우클릭 / 버전관리 / 드로잉) 은 그대로 살아남는다.

머지 시 다음 한 가지만 신경 쓰면 된다:
- **v1.26 측이 `<CommentPanel>` 에 새 props 를 추가했다면**, 그 props 가 `<CommentPanelResizable>` 시그니처에도 노출돼야 한다.

### 2-1. `CommentPanelResizable` 의 현재 props 시그니처

[src/components/scenes/CommentPanelResizable.tsx](../src/components/scenes/CommentPanelResizable.tsx) 의 `CommentPanelResizableProps`:

```ts
interface CommentPanelResizableProps {
  commentCount: number;
  sceneKey: string;
  counterpartSheetName?: string | null;
  counterpartSceneNo?: number | null;
  onCountChange?: (count: number) => void;
  focusCommentId?: string;
  sceneLabel?: string;
  heightClass?: string;
  className?: string;
  secondarySceneKey?: string;
  inlineEvents?: React.ComponentProps<typeof CommentPanel>['inlineEvents'];
  headerTitle?: string;
  headerRight?: React.ReactNode;
}
```

내부에서는 이 props 를 `CommentPanel` 로 forward 한다 (단순 pass-through):

```tsx
<CommentPanel
  sceneKey={sceneKey}
  secondarySceneKey={secondaryKey}
  onCountChange={onCountChange}
  focusCommentId={focusCommentId ?? null}
  sceneLabel={sceneLabel}
  inlineEvents={inlineEvents}
/>
```

### 2-2. v1.26 측이 새 prop 을 추가한 경우

예를 들어 v1.26 이 `CommentPanel` 에 다음과 같은 prop 을 추가했다고 가정:

```tsx
<CommentPanel
  ...
  onReactionToggle={...}
  onImageVersionChange={...}
  enableDrawingAnnotation={...}
/>
```

그러면 `CommentPanelResizable` 에도 같은 prop 을 패스스루로 노출:

```ts
interface CommentPanelResizableProps {
  // ...기존 그대로
  onReactionToggle?: React.ComponentProps<typeof CommentPanel>['onReactionToggle'];
  onImageVersionChange?: React.ComponentProps<typeof CommentPanel>['onImageVersionChange'];
  enableDrawingAnnotation?: React.ComponentProps<typeof CommentPanel>['enableDrawingAnnotation'];
}
```

그리고 forward:

```tsx
<CommentPanel
  ...기존
  onReactionToggle={onReactionToggle}
  onImageVersionChange={onImageVersionChange}
  enableDrawingAnnotation={enableDrawingAnnotation}
/>
```

이 패스스루 패턴은 type-safe (`React.ComponentProps<typeof CommentPanel>['X']`) 이라 v1.26 측이 CommentPanel props 시그니처를 바꿔도 `CommentPanelResizable` 가 따라간다.

### 2-3. SceneDetailModal / UnifiedSceneDetailModal 호출부 reconcile

머지 conflict 가 발생하면 다음 원칙:

1. **v1.27.0 측의 `<CommentPanelResizable .../>` 한 줄 JSX 를 살린다** (외곽 wrapper).
2. **v1.26 측이 `<CommentPanel ...>` 에 직접 추가한 props 들을 그 한 줄 안으로 옮겨 적는다**.
3. 만약 v1.26 측이 motion.div / div 외곽까지 새로 바꿨다면 (예: 새로운 layout 컨테이너 추가), 그 컨테이너 *안에* `<CommentPanelResizable>` 를 둔다. `CommentPanelResizable` 자체가 motion.div 외곽이므로 중첩되어도 OK.

#### 예시 — SceneDetailModal.tsx conflict 해결

**main (v1.27.0):**
```tsx
<CommentPanelResizable
  commentCount={commentCount}
  sceneKey={sceneKey}
  counterpartSheetName={counterpartSheetName}
  counterpartSceneNo={counterpartSceneNo}
  onCountChange={setCommentCount}
  focusCommentId={focusCommentId}
  sceneLabel={`${sheetName.replace(/_/g, ' ').replace(/^EP0?/, 'EP')}${scene.sceneId ? ` #${scene.sceneId}` : ''}`}
/>
```

**v1.26 (가정):**
```tsx
<motion.div className="w-80 ..." ...>
  <CommentPanel
    sceneKey={sceneKey}
    secondarySceneKey={...}
    onCountChange={setCommentCount}
    focusCommentId={focusCommentId}
    sceneLabel={...}
    onReactionToggle={handleReactionToggle}
    onImageContextMenu={handleImageContextMenu}
    enableDrawingAnnotation
  />
</motion.div>
```

**reconciled (머지 후):**
```tsx
<CommentPanelResizable
  commentCount={commentCount}
  sceneKey={sceneKey}
  counterpartSheetName={counterpartSheetName}
  counterpartSceneNo={counterpartSceneNo}
  onCountChange={setCommentCount}
  focusCommentId={focusCommentId}
  sceneLabel={`${sheetName.replace(/_/g, ' ').replace(/^EP0?/, 'EP')}${scene.sceneId ? ` #${scene.sceneId}` : ''}`}
  // ↓ v1.26 측이 CommentPanel 에 추가한 props 를 그대로 노출
  onReactionToggle={handleReactionToggle}
  onImageContextMenu={handleImageContextMenu}
  enableDrawingAnnotation
/>
```

당연히 `CommentPanelResizable` props 에도 위 3개를 패스스루 prop 으로 추가하고 내부에서 `<CommentPanel ... onReactionToggle={onReactionToggle} ... />` 로 forward.

UnifiedSceneDetailModal 도 동일 패턴.
