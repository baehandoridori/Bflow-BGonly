## 2. 아키텍처 전제 (이번 작업의 공통 배경)

- **B flow**: Electron + React 18 + TypeScript + Tailwind 3.4 + Zustand 앱. 저장소 `C:\Bflow-BGonly`. 데이터는 Supabase(PostgreSQL). **렌더러는 Supabase 를 직접 부르지 않는다** — `window.electronAPI.*`(preload IPC) → 메인 프로세스(`electron/main.ts`) → Supabase. 이번 작업은 **DB 테이블 1개 + 래퍼 함수 4개(마이그레이션) + IPC 채널 4개 + 실시간 신호 1개**를 추가한다.
- **CLAUDE.md 규칙 7(호출자 검증은 서버 세션 토큰으로)이 58 의 저장 방식을 결정한다.** 새 테이블 `comment_thread_todos` 는 anon 직접 권한이 없고(RLS 켜고 정책 0개 + `REVOKE`), 앱이 닿는 길은 `SECURITY DEFINER` 래퍼 4개뿐이다. 래퍼는 첫 줄에서 `public.app_session_user_id(p_session_token)`(라이브에 이미 존재, 실패는 전부 SQLSTATE `42501`)로 호출자를 확정하고, 작성자·완료자 이름을 `users` 명시 컬럼(`name`, `role` — `select *` 금지)에서 채운다. 클라이언트가 보내는 신원 주장(actor id)은 받지 않는다. 이 구조는 간트(`electron/ganttStore.ts`·`electron/ganttIpc.ts`, `DEVLOG/migrations/2026-09-05-app-sessions-gantt-auth.sql`)가 라이브에서 검증한 것과 동일하며, 이번 코드는 그 파일들을 미러링한다.
  - **토큰은 main 안에서만**: `sessionManager.getSessionTokenFor(actorId)`(`electron/sessionManager.ts:111-116`)는 canonical 사용자와 일치할 때만 토큰을 돌려주고 아니면 `'로그인 세션이 필요합니다. 다시 로그인해 주세요.'` 를 던진다. 토큰은 IPC 응답·broadcast 에 실리지 않는다.
  - **호출자 id 는 main 의 세션에서**: `getSessionOriginOrThrow()`(`electron/main.ts:2513-2529`)가 `{ userId, epoch, role }` 을 준다. IPC 핸들러는 렌더러가 보낸 `requestEpoch`(preload 의 `canonicalSessionEpoch`, `electron/preload.ts:58-62`·`771-779` 에서 유지)와 대조해 오래된 화면의 요청을 거부하고, `await` 뒤 세션이 바뀌었으면 응답을 폐기한다(`ganttIpc.ts:15-38` 패턴). **커밋된 변경의 `onChanged` 알림은 폐기 검사보다 먼저** 나간다.
  - **세션이 없을 때**: `getSessionOriginOrThrow` 의 원래 문구는 `'세션에 로그인 사용자 정보가 없습니다 (비공개 일정)'` 이다. 팀 할 일 IPC 는 이를 잡아 `'로그인 세션이 필요합니다. 다시 로그인해 주세요.'` 로 통일한다(작업 2 (b)).
- **실시간**: 테이블을 `supabase_realtime` publication 에 넣지 않는다(행 내용이 anon 구독자에게 흘러가므로). 대신 statement 단위 AFTER 트리거가 `realtime.send(..., 'thread-todos-changed', 'bflow-realtime', false)` 로 **내용 없는 신호**만 보낸다(간트 `gantt_notify_change` 미러). `electron/realtime.ts` 의 기존 채널(`supabase.channel('bflow-realtime')`)에 `broadcast` 리스너 1줄을 추가하면 main 이 `onThreadTodosChange` 를 받아 `broadcastToAllWindows('thread-todos:changed', {})`(`electron/main.ts:716-733`, 메인 창 + 모든 위젯 팝업 창)로 뿌린다. 자기 창의 쓰기는 IPC 핸들러의 `onChanged` 로도 같은 채널을 받으므로 Realtime 이 끊겨도 자기 창은 갱신된다. 렌더러 섹션은 300ms 디바운스 후 목록을 다시 읽는다.

export const THREAD_TODO_RESPONSE_DISCARDED = '로그인 세션이 변경되어 할 일 응답을 폐기했습니다.';

/** 서버 to_jsonb 그대로(snake_case). 렌더러도 이 타입을 직접 소비한다 (CharacterBoardTabRow 관행). */
export interface ThreadTodoRow {
  id: string;
  thread_key: string;
  text: string;
  created_by: string;
  created_by_name: string;
  created_at: string;
  done_at: string | null;
  done_by: string | null;
  done_by_name: string | null;
}

/** 연속 공백은 한 칸으로, 앞뒤 공백 제거. 문자열이 아니면 빈 문자열. (서버 regexp_replace 와 같은 규칙) */
export function sanitizeThreadTodoText(raw: unknown): string {
  return typeof raw === 'string' ? raw.replace(/\s+/g, ' ').trim() : '';
}

export function isValidThreadTodoText(text: string): boolean {
  return text.length > 0 && text.length <= THREAD_TODO_TEXT_MAX;
}

export function isValidThreadKey(key: unknown): key is string {
  return typeof key === 'string' && key.trim() !== '' && key.length <= THREAD_TODO_KEY_MAX;
}

export function isThreadTodoRow(value: unknown): value is ThreadTodoRow {
  if (!value || typeof value !== 'object') return false;
  const r = value as Record<string, unknown>;
  const str = (k: string) => typeof r[k] === 'string';
  const strOrNull = (k: string) => r[k] === null || typeof r[k] === 'string';
  return str('id') && str('thread_key') && str('text') && str('created_by') && str('created_by_name') && str('created_at')
    && strOrNull('done_at') && strOrNull('done_by') && strOrNull('done_by_name');
}

/** UI 표시용 판정. 최종 판정은 서버(SECURITY DEFINER 래퍼 안의 users.role)가 한다. */
export function canDeleteThreadTodo(row: ThreadTodoRow, user: { id: string; role?: string } | null | undefined): boolean {
  return !!user && (row.created_by === user.id || user.role === 'admin');
}

function missingMigration(error: RpcError): boolean {
  return ['42P01', 'PGRST205', '42883', 'PGRST202'].includes(error.code ?? '');
}

export function createThreadTodoStore(
  client: ThreadTodoRpcClient,
  session: ThreadTodoSessionResolver = { tokenFor: (actorId) => sessionResolver.tokenFor(actorId) },
) {
  async function list(actorId: string, threadKey: unknown): Promise<ThreadTodoRow[]> {
    const key = validateThreadKey(threadKey);
    const token = session.tokenFor(actorId);
    const { data, error } = await client.rpc('comment_thread_todos_session_list', { p_session_token: token, p_thread_key: key });
    if (error) fail(error);
    return Array.isArray(data) ? data.filter(isThreadTodoRow) : [];
  }
  async function add(actorId: string, threadKey: unknown, text: unknown): Promise<ThreadTodoRow> {
    const key = validateThreadKey(threadKey);
    const clean = validateTodoText(text);
    const token = session.tokenFor(actorId);
    const { data, error } = await client.rpc('comment_thread_todos_session_add', { p_session_token: token, p_thread_key: key, p_text: clean });
    if (error) fail(error);
    return row(data);
  }
  async function setDone(actorId: string, id: unknown, done: unknown): Promise<ThreadTodoRow> {
    const todoId = validateTodoId(id);
    const token = session.tokenFor(actorId);
    const { data, error } = await client.rpc('comment_thread_todos_session_set_done', { p_session_token: token, p_id: todoId, p_done: done === true });
    if (error) fail(error);
    return row(data);
  }
  async function remove(actorId: string, id: unknown): Promise<{ ok: boolean; deleted: boolean }> {
    const todoId = validateTodoId(id);
    const token = session.tokenFor(actorId);
    const { data, error } = await client.rpc('comment_thread_todos_session_delete', { p_session_token: token, p_id: todoId });
    if (error) fail(error);
    return { ok: true, deleted: (data as { deleted?: unknown } | null)?.deleted === true };
  }
  return { list, add, setDone, remove };
}

    let now: SessionOrigin;
    // 커밋 뒤 세션이 사라진 경우(로그아웃)도 '폐기' 다 — 서버엔 저장됐으므로 실패로 보이면 안 된다.
    try { now = originOrThrow(); } catch { throw new Error(THREAD_TODO_RESPONSE_DISCARDED); }
    if (origin.userId !== now.userId || origin.epoch !== now.epoch) throw new Error(THREAD_TODO_RESPONSE_DISCARDED);
  }
  function checkRequestEpoch(requestEpoch: unknown, origin: SessionOrigin) {
    if (!Number.isSafeInteger(requestEpoch) || requestEpoch !== origin.epoch) throw new Error('로그인 세션이 변경되었습니다. 화면을 다시 열어 주세요.');
  }
  // 커밋된 변경은 요청한 세션이 바뀌었어도 다른 창을 무효화해야 한다 → onChanged 를 current 검사보다 먼저.
  function notify() {
    try { deps.onChanged(); } catch (error) { console.warn('[thread-todo] 변경 알림 실패:', error); }
  }
  ipc.handle('thread-todo:list', async (_event, threadKey, requestEpoch) => {
    const origin = originOrThrow();
    checkRequestEpoch(requestEpoch, origin);
    const result = await store.list(origin.userId, threadKey);
    current(origin);
    return result;
  });
  ipc.handle('thread-todo:add', async (_event, threadKey, text, requestEpoch) => {
    const origin = originOrThrow();
    checkRequestEpoch(requestEpoch, origin);
    const result = await store.add(origin.userId, threadKey, text);
    notify();
    current(origin);
    return result;
  });
  ipc.handle('thread-todo:set-done', async (_event, id, done, requestEpoch) => {
    const origin = originOrThrow();
    checkRequestEpoch(requestEpoch, origin);
    const result = await store.setDone(origin.userId, id, done);
    notify();
    current(origin);
    return result;
  });
  ipc.handle('thread-todo:delete', async (_event, id, requestEpoch) => {
    const origin = originOrThrow();
    checkRequestEpoch(requestEpoch, origin);
    const result = await store.remove(origin.userId, id);
    notify();
    current(origin);
    return result;
  });

- **세션 없음**: IPC 는 `'로그인 세션이 필요합니다. 다시 로그인해 주세요.'` 로 통일 — `'(비공개 일정)'` 문구가 팀 할 일 화면에 새지 않는다(테스트가 단언).
- **입력 검증 순서**: 저장소는 텍스트/키/id 검증을 토큰 조회 **전**에 끝낸다 → 잘못된 입력이 세션 오류로 둔갑하지 않는다(테스트 `입력 검증은 토큰을 꺼내기 전에`).
- **커밋 후 응답 폐기**: IPC 가 `await` 뒤 세션 변경을 감지하면 공유 상수 `THREAD_TODO_RESPONSE_DISCARDED` 문구로 throw 한다(저장·`onChanged` 는 이미 끝남). 작업 3 의 섹션은 이 문구를 오류로 보이지 않고 재조회에 맡긴다.
- **마이그레이션 미적용 앱**: RPC 가 `PGRST202` → `'팀 할 일 저장소 준비가 필요합니다…'` 안내, 댓글은 정상. 게이트는 머지 전(부록 A-2).
- mock 의 `widgetOpenPopup` 은 optional 타입이라 추가만 하면 된다. 부수 효과: 미리보기에서 현황판 헤더 '새 창으로'·위젯 팝아웃 버튼도 노출된다(클릭 시 로그만) — 의도된 것이며 기존 미리보기 테스트에 영향 없음.

  // 첫 로드 + 로그인 세션이 바뀔 때 재조회. 팝업 창은 세션 동기화로 같은 사람의 재로그인에도 currentUser 객체가
  //   새로 들어오므로(id 가 아니라 객체에 의존) '다시 로그인해 주세요' 안내가 저절로 걷힌다. 메인 창은 로그아웃 시
  //   섹션이 언마운트됐다가 로그인 후 다시 마운트되므로 첫 로드가 곧 재조회다.
  useEffect(() => { void load(); }, [load, currentUser]); // eslint-disable-line react-hooks/exhaustive-deps

  // 변경 신호: 자기 창 IPC onChanged + DB broadcast 두 경로가 300ms 안에 한 번으로 합쳐진다.
  useEffect(() => {
    let timer: ReturnType<typeof setTimeout> | null = null;
    const unsubscribe = window.electronAPI.onThreadTodosChanged(() => {
      if (timer) clearTimeout(timer);
      timer = setTimeout(() => {
        timer = null;
        // 뮤테이션 진행 중이면 그 finally 가 어차피 다시 읽으므로 건너뛴다.
        if (inFlightRef.current === 0) void load();
      }, SIGNAL_DEBOUNCE_MS);
    });
    return () => {
      unsubscribe();
      if (timer) clearTimeout(timer);
    };
  }, [load]);

  const runMutation = useCallback(async (id: string, work: () => Promise<void>) => {
    // 진행 중인 목록 조회 응답이 낙관 상태를 덮지 않게 폐기한다(끝난 뒤 반드시 다시 읽는다).
    if (loadPendingRef.current) {
      loadSeqRef.current += 1;
      loadPendingRef.current = false;
    }
    inFlightRef.current += 1;
    setBusyIds((prev) => new Set(prev).add(id));
    try {
      await work();
    } finally {
      inFlightRef.current -= 1;
      if (mountedRef.current) {
        setBusyIds((prev) => { const next = new Set(prev); next.delete(id); return next; });
        // 성공·실패·응답 폐기 모두 서버 상태로 수렴 — 마지막 뮤테이션이 끝나면 반드시 다시 읽는다.
        if (inFlightRef.current === 0) void load();
      }
    }
  }, [load]);

  const submitDraft = async () => {
    const text = sanitizeThreadTodoText(draft);
    if (!isValidThreadTodoText(text)) return;
    const tempId = createUuid();
    const optimistic: ThreadTodoRow = {
      id: tempId, thread_key: threadKey, text,
      created_by: currentUser.id, created_by_name: currentUser.name,
      created_at: new Date().toISOString(), done_at: null, done_by: null, done_by_name: null,
    };
    setItems((prev) => [...prev, optimistic]);
    setDraft('');
    await runMutation(tempId, async () => {
      try {
        const saved = await window.electronAPI.threadTodoAdd(threadKey, text);
        setItems((prev) => prev.map((r) => (r.id === tempId ? saved : r)));
      } catch (err) {
        if (isDiscardedResponse(err)) return; // 서버엔 저장됨 — finally 의 재조회가 임시 항목을 실제 행으로 바꾼다
        setItems((prev) => prev.filter((r) => r.id !== tempId));
        setDraft((cur) => (cur.trim() === '' ? draft : cur)); // 새로 치기 시작하지 않았다면 원문 복구
        sonnerToast.error(cleanIpcErrorMessage(err, '팀 할 일을 추가하지 못했어요'));
      }
    });
  };

  const toggleDone = async (item: ThreadTodoRow) => {
    const done = item.done_at == null;
    const now = new Date().toISOString();
    // 서버 규칙 미러: 완료는 최초 완료자 유지, 해제는 세 필드 모두 비움.
    const optimistic: ThreadTodoRow = done
      ? { ...item, done_at: item.done_at ?? now, done_by: item.done_by ?? currentUser.id, done_by_name: item.done_by_name ?? currentUser.name }
      : { ...item, done_at: null, done_by: null, done_by_name: null };
    setItems((prev) => prev.map((r) => (r.id === item.id ? optimistic : r)));
    await runMutation(item.id, async () => {
      try {
        const saved = await window.electronAPI.threadTodoSetDone(item.id, done);
        setItems((prev) => prev.map((r) => (r.id === item.id ? saved : r)));
      } catch (err) {
        if (isDiscardedResponse(err)) return;
        setItems((prev) => prev.map((r) => (r.id === item.id ? item : r)));
        sonnerToast.error(cleanIpcErrorMessage(err, '완료 표시를 바꾸지 못했어요'));
      }
    });
  };

  const removeItem = async (item: ThreadTodoRow) => {
    setItems((prev) => prev.filter((r) => r.id !== item.id));
    await runMutation(item.id, async () => {
      try {
        await window.electronAPI.threadTodoDelete(item.id);
        if (item.created_by !== currentUser.id) sonnerToast(`${item.created_by_name}님이 적은 할 일을 지웠어요`);
      } catch (err) {
        if (isDiscardedResponse(err)) return;
        setItems((prev) => (prev.some((r) => r.id === item.id) ? prev : [...prev, item].sort(byCreated)));
        sonnerToast.error(cleanIpcErrorMessage(err, '팀 할 일을 지우지 못했어요'));
      }
    });
  };

  const toggleCollapsed = () => {
    const next = !collapsed;
    setCollapsed(next);
    try { localStorage.setItem(COLLAPSED_KEY, next ? '1' : '0'); } catch { /* ignore */ }
  };

  const openCount = items.filter((r) => r.done_at == null).length;
  const draftValid = isValidThreadTodoText(sanitizeThreadTodoText(draft));

  return (
    <section aria-label="팀 할 일" className="shrink-0 border-b border-bg-border px-3 pb-2">
      <button
        type="button"
        onClick={toggleCollapsed}
        aria-expanded={!collapsed}
        className="flex w-full items-center gap-1.5 py-1.5 text-[11px] font-bold text-text-secondary hover:text-text-primary cursor-pointer"
      >
        {collapsed ? <ChevronRight size={12} /> : <ChevronDown size={12} />}
        <ListTodo size={12} />
        <span>팀 할 일</span>
        <span className="ml-auto tabular-nums font-medium text-text-secondary/60">{openCount}/{items.length}</span>
      </button>
      {!collapsed && (
        <div className="space-y-1">
          {notice && (
            <p role="alert" className="flex items-center justify-between gap-2 text-[11px] text-text-secondary">
              <span>{notice}</span>
              <button type="button" onClick={() => void load()} className="shrink-0 underline cursor-pointer">다시 불러오기</button>
            </p>
          )}
          <ul className="max-h-48 overflow-y-auto space-y-0.5">
            {items.map((item) => {
              const busy = busyIds.has(item.id);
              return (
                <li key={item.id} className={cn('group/todo flex items-start gap-2 rounded px-1 py-0.5 hover:bg-bg-primary/50', busy && 'opacity-60')}>
                  <label className="flex min-w-0 flex-1 items-start gap-2 cursor-pointer">
                    <input
                      type="checkbox"
                      checked={item.done_at != null}
                      disabled={busy}
                      onChange={() => void toggleDone(item)}
                      aria-label={`${item.text} 완료 표시`}
                      className="mt-0.5 h-3.5 w-3.5 shrink-0 accent-accent cursor-pointer"
                    />
                    <span className="min-w-0 flex-1">
                      <span className={cn('block text-xs break-words', item.done_at ? 'line-through text-text-secondary/60' : 'text-text-primary')}>
                        {item.text}
                      </span>
                      <span className="block text-[10px] text-text-secondary/60">
                        {item.created_by_name}{item.done_by_name ? ` · ${item.done_by_name} 완료` : ''}
                      </span>
                    </span>
                  </label>
                  {!busy && canDeleteThreadTodo(item, currentUser) && (
                    <button
                      type="button"
                      onClick={() => void removeItem(item)}
                      title="팀 할 일 지우기"
                      aria-label="팀 할 일 지우기"
                      className="shrink-0 rounded p-0.5 text-text-secondary/40 opacity-0 transition-opacity group-hover/todo:opacity-100 focus-visible:opacity-100 hover:text-text-primary cursor-pointer"
                    >
                      <Trash2 size={12} />
                    </button>
                  )}
                </li>
              );
            })}
            {items.length === 0 && !loading && !notice && (
              <li className="py-2 text-center text-[11px] text-text-secondary/40">아직 팀 할 일이 없어요</li>
            )}
          </ul>
          <form onSubmit={(e) => { e.preventDefault(); void submitDraft(); }} className="flex items-center gap-1">
            <input
              value={draft}
              onChange={(e) => setDraft(e.target.value)}
              maxLength={THREAD_TODO_TEXT_MAX}
              placeholder="팀 할 일 추가 (Enter)"
              aria-label="새 팀 할 일"
              className="min-w-0 flex-1 rounded bg-bg-primary/60 px-2 py-1 text-xs text-text-primary placeholder:text-text-secondary/40 outline-none focus:ring-1 focus:ring-accent"
            />
            <button
              type="submit"
              disabled={!draftValid}
              aria-label="팀 할 일 추가"
              className="shrink-0 rounded p-1 text-text-secondary hover:text-accent disabled:opacity-40 cursor-pointer"
            >
              <Plus size={14} />
            </button>
          </form>
        </div>
      )}
    </section>
  );
}

- **같은 항목 동시 체크**: 서버 `COALESCE` 로 최초 완료자 유지, 낙관 상태도 같은 규칙 → 늦은 쪽은 서버 행으로 교체(이름만 상대로 바뀜).
- **삭제된 항목 체크**: 서버 P0002(`'이미 지워진 할 일이에요.'`) → 항목 롤백 + 토스트 + 재조회로 사라짐.
- **저장 전 임시 항목**: temp id 가 `busyIds` 에 있어 체크박스 disabled·삭제 버튼 미렌더.
- **동시에 두 항목 조작 중 하나 실패**: 항목 단위 역연산 롤백이라 다른 항목의 낙관 상태 유지.
- **초기 로드 중 추가**: `runMutation` 이 진행 중 load 응답을 폐기하고, 마지막 뮤테이션의 finally 가 무조건 재조회한다(기존 항목이 신호 유무와 무관하게 채워진다). `loading` 은 폐기된 load 에서도 해제된다. 신호 리스너는 뮤테이션 진행 중이면 건너뛴다(finally 가 대신 읽는다).
- **커밋 후 응답 폐기**(IPC 가 `THREAD_TODO_RESPONSE_DISCARDED` 문구로 throw — 세션이 바뀐 경우와 로그아웃으로 사라진 경우 모두): 세 뮤테이션 모두 `isDiscardedResponse` 로 걸러 롤백·토스트 없이 finally 재조회에 맡긴다 — 서버엔 이미 저장됐으므로 "실패했는데 항목이 있다" 는 혼란을 만들지 않는다. finally 재조회까지 실패하면 임시 항목이 안내 문구와 함께 남고, 다음 성공 재조회(재로그인·'다시 불러오기')에서 실제 행으로 교체된다.
- **뮤테이션 중 수동 재조회**('다시 불러오기'·`currentUser` 변경): `load` 는 뮤테이션 진행 중이면 스스로 건너뛴다(finally 가 대신 읽는다) — 낙관 상태가 중간에 덮이지 않는다.
- **스레드 키 변경**: `CommentPanel` 이 `key={effectiveSceneThreadKey}` 로 섹션을 리마운트하므로 이전 스레드의 항목·진행 중 조회가 새 스레드에 섞이지 않는다.
- **재로그인**: `useEffect(() => { void load(); }, [load, currentUser])` — 팝업 창은 세션 동기화로 같은 사람의 재로그인에도 새 객체가 들어와 안내가 걷히고, 메인 창은 로그아웃 시 섹션이 언마운트됐다가 다시 마운트되므로 첫 로드가 곧 재조회다.
- **관리자가 남의 항목 삭제**: 확인 창 없이 지우고 `'{이름}님이 적은 할 일을 지웠어요'` 토스트 1줄.
- **텍스트 수정·순서 변경**: 이번 범위 밖(부록 C).
- **스레드 키 `''`(통합 모달 예외)**: 섹션 미렌더 — 댓글은 보이는데 할 일만 없는 상태가 의도된 동작. 씬 재번호·파트 이동으로 키가 바뀌면 댓글 읽음 상태처럼 새 스레드로 시작한다(고아 행 방치).
