### 사용자 확인 후 변경 (같은 날)

- 사용자가 프리뷰에서 직접 확인하고 "기즈모가 블렌더처럼 더 잘 보였으면" 요청 → 굵은 단방향 화살표·굵은 고리·가운데 점, 블렌더 축 색(빨강 가로, 초록 세로, 파랑이 위)으로 변경. 같은 검증 도구에서 이동·회전·크기 모양 캡처, 빨강(가로)·파랑(높이) 화살표 드래그와 되돌리기, 반대쪽 빈 곳 무반응, 가리킴 강조(노란색 + 축 안내선)를 확인했다. 가리킴 강조는 검증 도구의 마우스 이동 이벤트가 종류 정보를 싣지 않아 기즈모의 가리킴 처리를 직접 호출해 확인했다.
- 이 변경의 독립 검토(2관점)에서 "반대쪽 손잡이를 빼면 뒤쪽에서 볼 때 빨강·초록 화살표를 눌러도 다른 축이 잡힌다"는 결함이 나와, 화면에 그려진 손잡이를 먼저 잡도록 고쳤다. 같은 검증 도구에서 화면을 뒤쪽으로 돌린 뒤 다시 확인: 빨강 화살표 드래그 → 가로 위치만 403.37 → 826.6, 파랑 화살표 밑동 드래그 → 높이만 170 → 292.5, 크기 모드의 빨강 네모 → 가로 길이만 180 → 374.72. 위 명령 검사 표의 수치는 이 변경까지 포함한 최종 실행이다.

### 확인하지 못한 것

### 화면 검증 결과

- **확대·축소**: 휠 한 칸마다 마우스 아래의 도면 좌표가 그대로였다(예: (190.854, 229.162) 고정, 100% → 127% → 205%). 다른 자리에서 줄여도 그 자리 기준. 한계 10%와 400%에서 멈춤. `맞춤`은 기본 영역 안의 도면에서 100%·처음 자리. `+` `−` `0` 키 동작(125% → 80% → 100%). 3D에 다녀온 뒤에도 평면에서 휠이 듣는다.
- **손잡이 크기**: 회전 14×14px, 크기 12×12px이 49%·100%·205%에서 같다.
- **스냅(옮기기)**: 새 공간의 왼쪽을 옆 방 오른쪽 벽 근처로 끌면 가로 위치가 벽과 같은 860, 붙지 않은 세로는 정수(389). 끄는 동안에만 안내선, 놓으면 사라짐. 되돌리기 한 번으로 원래 값(899.31, 381.16).
- **스냅(크기)**: 오른쪽 아래 손잡이로 늘리면 오른쪽 끝이 도면 테두리 1000, 아래 끝이 옆 방 아랫변 540.
- **회전 걸림**: 88.6° 근처에서 놓으면 90, 60° 근처는 60.26 그대로.
- **Alt·스냅 버튼**: Alt를 누른 채 끌면 붙지 않은 값(863.25, 388.89). 마우스를 먼저 떼든 Alt를 먼저 떼든 그 뒤 `+` 키가 들었다(포커스가 도면에 남음). 끄는 도중 Alt를 떼면 다시 붙는다(860). `스냅`을 끄면 붙지 않고 설정이 기억된다.
- **이름 칸**: 사각형을 그리면 `새 공간`이 선택된 이름 칸이 포커스를 가진 채 열림 → 입력 → Enter로 확정, 포커스는 도면으로. 되돌리기 한 번에 그리기와 이름이 함께 취소. Esc는 `새 공간`으로 남김. 다른 곳 클릭은 확정. 다각형 도구의 `다각형 완성` 뒤에도 열린다.
- **더블클릭·F2**: 상세 도면이 없는 공간과 카메라는 더블클릭으로 이름 칸. 상세 도면이 연결된 공간(학교 도면의 본관)은 보기 상태와 편집 중 모두 그 도면으로 들어가고, F2로는 이름 칸이 열린다. 잠근 기호는 더블클릭·F2에 반응하지 않는다.
- **겹친 카메라**: 같은 자리의 카메라 둘을 천천히 누르면 번갈아 선택되고, 빠른 더블클릭은 넘기지 않고 처음 눌린 카메라의 이름 칸을 연다.
- **한글 조합(흉내)**: 조합 중 다른 곳을 누르면 글자가 온전히 확정(`창고`). 조합이 끝난 뒤 Enter 한 번으로 확정(`복도`). 조합이 열린 채의 Enter는 무시된다.
- **다각형 점**: 네모 공간에서 `다각형으로 바꾸기` → 점 4개와 변 가운데 `+` 4개. 점 하나를 끌면 그 점만 움직임. `+`를 끌면 점이 하나 늘고, 그 점을 고른 뒤 Delete로 지워짐. 점이 3개일 때 Delete는 안내 문구만 띄우고 공간은 남는다. 되돌리기는 조작마다 한 단계. 점을 옆 방 모서리 3px 옆으로 끌면 정확히 그 모서리(860, 540)에 놓인다.
- **안내 문구가 떠 있을 때의 점 끌기(최종 검토 반영 뒤)**: 문구가 떠 있는 채로 점을 끌어도 점이 포인터를 따라오고, 놓으면 문구가 사라진다.
- **3D·저장**: 다각형으로 바꾼 뒤 3D 전환 정상, `도면 저장` 후 새로 고침해도 다각형(점 3개, x 860)이 남는다.
- **기존 동작**: 이동 도구와 가운데 버튼으로 화면 옮기기, 기호(의자) 놓기, 카메라 방향 손잡이(방향만 바뀜), 잠근 항목은 끌어도 그대로, 선택 후 Delete는 확인 창. 보기 상태에서 공간 위를 끌면 선택만 되고 화면은 움직이지 않는다(v1.130.0과 같음, ② 묶음에서 바꿀 예정).
- **작은 창·밝은 화면**: 740×900에서 가로 넘침 없음, 점 손잡이와 이름 칸이 보이고 아래 줄 안내가 두 줄로 들어간다. 콘솔 오류 0건(검사 도구의 보안 안내 제외).

### 화면 검증 방법

- ①과 같다: 앱과 같은 엔진(Electron 33.4.11)을 화면에 보이지 않게 띄워 미리보기(한솔 시험 계정)에 실제 마우스·휠·키 입력을 넣고 화면 값과 캡처로 확인했다. 창 1440×900, 일부는 740×900과 밝은 화면.
- 이 검사 창의 가짜 입력은 포인터 캡처가 걸리지 않는다. 그래서 끌기가 도구 줄 위에서 끝나는 경우(캡처로 이어지는 끌기)는 검사 창에서 재현하지 못했고, 끌기는 모두 도면 영역 안에서 시작하고 끝냈다.

### 화면 검증 결과

- **보기 상태**: 방 위에서 누르기만 하면 선택이 바뀌지 않고, 끌면 화면이 움직이며 선택은 그대로다. 움직이지 않고 떼면 그 방이 선택된다.
- **선택 상자**: 편집 중 Shift를 누른 채 방 안에서 끌면 점선 상자가 보이고, 놓으면 안의 의자 둘만 선택된다(방은 선택되지 않음 — 벽 규칙). 방 바깥 빈 곳에서 시작해 방의 왼쪽 벽을 지나는 상자는 그 방과 상자 안의 의자를 함께 고른다. 글자 선택(파란 강조)은 생기지 않는다.
- **Shift+클릭**: 하나씩 더해지고 빠진다.
- **묶음 이동**: 고른 의자 둘 중 하나를 끌면 둘이 같은 만큼 움직이고(스냅 적용: 방의 가운데 선에 붙음), 끄는 동안 되돌리기가 꺼져 있다가 놓으면 한 단계가 생기며, 되돌리기 한 번에 둘 다 원위치.
- **끄는 중 Esc**: 상자가 사라지고 선택은 그대로, 그 뒤 마우스를 떼도 바뀌지 않는다. Esc는 선택을 풀지 않는다(설계대로).
- **화면 이동**: 스페이스를 누른 채 방 위에서 끌면 화면만 움직이고 방은 제자리, 페이지는 내려가지 않는다. 스페이스를 누르고 있는 동안 커서가 손 모양. `배경 라이브러리 새로고침` 버튼, `도면 탐색` 탭 버튼, 잠금 체크 칸을 누른 바로 뒤에도 화면 이동이 되고, 스페이스를 뗄 때 그 버튼·체크 칸이 다시 눌리지 않는다. 휠 버튼으로 방 위에서 끌어도 화면이 움직인다. 도구 이름은 `화면 이동`.
- **겹친 공간(평면)**: 작은 방을 그린 뒤 그 위로 큰 외곽을 나중에 그려도 그리는 순서가 넓은 것부터라 작은 방이 위에 있고 눌린다. 같은 자리를 천천히 다시 누르면 작은 방 → 교실 → 외곽 → 다시 작은 방. 빠른 더블클릭은 넘기지 않고 처음 눌린 방의 이름 칸을 연다.
- **겹친 공간(3D)**: 같은 순서로 넘어간다. 오른쪽 버튼으로 화면을 돌린 뒤 같은 방을 다시 눌러도 그 방 그대로다. 캔버스의 연속 클릭은 `detail` 1, 2로 오고, 보조 평면도의 노드 클릭도 1, 2로 온다.
- **묶음 요약**: `여러 개 선택 · 2개 선택 · 공간 2`와 `모두 잠그기`·`잠금 풀기`·`선택한 2개 삭제`. 모두 잠그면 `잠긴 것 2`가 붙고 삭제 버튼은 `선택한 0개 삭제`로 꺼진다. 삭제는 확인 창을 거쳐 둘 다 지우고 포커스가 도면으로 돌아오며, Ctrl+Z 한 번에 둘 다 돌아온다.
- **3D 다녀오기**: 평면에서 둘을 고른 채 3D로 가면 대표 하나만 다루고 "평면에서 고른 2개는 그대로 있어요…" 안내가 보이며, 평면으로 돌아오면 둘이 그대로 선택돼 있다.
- **①의 기능**: 보기 상태에서 연결된 공간을 더블클릭하면 그 도면으로 들어감, 그리면 이름 칸, 하나를 옮길 때 스냅(옆 방의 아랫변·오른쪽 끝에 정확히 붙음), 휠 확대와 `0`, 다각형의 점 손잡이, 빈 곳 클릭으로 선택 비우기가 그대로다.
- **작은 창·밝은 화면**: 740×900에서 가로 넘침 없음, 점선 상자와 요약이 보인다. 콘솔 오류 0건(검사 도구의 보안 안내 제외).

### 확인하지 못한 것

- 끌기가 도면 밖(도구 줄·속성 칸 위)에서 끝나는 경우. 검사 창의 가짜 입력으로는 포인터 캡처가 걸리지 않아 재현하지 못했다. v1.130.0부터 쓰던 같은 캡처 코드이고 실제 마우스에서는 이어진다.
- 설치된 앱의 창에서 스페이스·Shift·Alt 조합, 실제 터치패드.
- 설계 13절의 항목 중 큰 도면(노드 수백 개)에서의 상자 속도, 권한이 없는 계정의 화면, 다른 사용자의 저장으로 도면이 바뀌는 동안의 선택은 화면에서 눌러 보지 않았다(코드 검토와 단위 테스트로만 확인).
- 설치 앱·운영 DB에서의 동작. 이번 묶음은 저장 내용과 운영 DB를 바꾸지 않는다.
