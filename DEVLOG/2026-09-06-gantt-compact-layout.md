# 간트 작업 공간 정리

사용자 화면 피드백을 기준으로 기존 디자인과 저장 동작을 유지하며 표시 밀도를 조정한다.

## 범위

- 차트의 상시 종류·세부정보·상위 위치 안내를 제거하고 호버/키보드 초점에서 제공한다. 메모는 전체 내용에 접근할 수 있어야 한다.
- 차트 자체의 그룹 펼침 버튼을 명확히 하고 그룹 기간은 위·왼쪽·오른쪽이 닫힌 모양으로 표시한다.
- 사이드바의 폴더·프로젝트·그룹 접힘과 차트 접힘을 독립 저장한다. 눈 아이콘의 명시적 차트 표시/숨김과 항목 선택 시 위치 찾기는 유지한다.
- 상단 생성 위치와 일상적인 성공 문구, 중복 사용법을 제거하고 작업 도구의 여백을 줄인다. 저장 실패와 권한 안내는 유지한다.
- 상세 제목의 줄바꿈과 자동 높이, 입력·레이블·선택 메뉴의 글자 배율 및 간격을 정리한다.

## 검증 기준

- 실제 GanttView 콜백에서 양방향 접힘 독립, 기존 설정 이관/재로드, 생성·이동 후 사이드바 상태 보존을 검증한다.
- 호버 메모 끝까지 읽기, 이름·그룹 버튼, 상세 긴 제목의 저장/실패 보호를 관련 회귀 시험과 실제 preview로 확인한다.
- 기본 창 크기와 낮은 창, 라이트/다크에서 상단·상세 높이와 글자 정렬을 확인한다.
- typecheck, 관련 시험, build:vite, 독립 로컬 리뷰 후 최종 병합의 Windows build와 manifest-last 배포를 검증한다.

## 변경 전과 후

| 변경 전 | 변경 후 |
|---|---|
| 종류와 위치 안내가 차트에 상시 표시 | 이름과 진행률 중심, 세부정보는 호버 표시 |
| 긴 메모가 일부만 표시 | 전체 메모를 읽을 수 있는 화면 안쪽 툴팁 |
| 그룹 버튼이 눈에 띄지 않고 아래쪽이 이어진 기간 모양 | 이름 앞 펼침 버튼과 위·왼쪽·오른쪽이 이어진 그룹 기간 |
| 트리와 차트가 접힘 상태를 공유 | 각 영역의 접힘 상태와 설정을 별도 관리 |
| 생성 위치·성공 안내·중복 도움말이 상단 공간 차지 | 필요한 도구와 오류 안내 중심으로 축소 |
| 상세 제목 한 줄, 입력과 선택창의 글자 크기 불균형 | 제목 줄바꿈과 자동 높이, 일관된 글자 배율과 간격 |

## 로컬 리뷰와 화면 검증

- 두 독립 리뷰에서 발견한 툴팁 Escape 전파와 Space 팬 충돌을 수정했다. 열린 메모의 Escape만 소비하고 원래 이름으로 초점을 돌려주며, View와 Canvas는 툴팁 내부 키보드 입력을 제외한다. 수정 후 양쪽 리뷰 모두 남은 P1/P2/P3 없음.
- Inspector 최대 크기 경계를 실제로 재현했다. 1024×640, 전체 1.2 × 본문 1.4 배율, 한글 200자 제목에서 제목이 608px까지 커졌다. 자동 높이를 `min(240px, 30vh)`로 제한하고 내부 스크롤을 허용한 뒤 본문 139px와 하단 동작 92px가 창 안에 유지됐다. Ctrl+End로 제목 끝까지 접근했다.
- 배한솔 preview로 로그인하고 1280×720 및 1024×640, 다크·라이트 모드를 확인했다. 기본 배율의 긴 제목은 139px로 전체가 표시됐고, 제목·입력·선택 항목의 실제 글자 크기는 13px로 일치했다.
- 사이드바 그룹 접기 후 차트 작업 유지, 차트 그룹 접기 후 사이드바 작업 유지가 양방향으로 확인됐다. 그룹 테두리는 위·오른쪽·왼쪽 3px, 아래 0px였다.
- 80줄·2,404자 메모의 마지막 문장까지 DOM에 보존되고 툴팁 내부 스크롤로 도달했다. F2 진입, Space 스크롤, Ctrl+End, Escape 후 상세 유지·원래 이름 초점 복귀를 실제 preview에서 확인했다. 마우스 진입·이탈 지연과 고스트 회귀는 자동 이벤트 시험으로 검증했다.
- 임시 프로젝트와 하위 2개 항목은 제품의 삭제 흐름으로 정리했다. 테마·글자·차트 표시·viewport를 원상 복원했고 preview 콘솔 error는 0건이었다.

실제 설치된 Electron 앱의 업데이트 적용 E2E와 팀원 PC의 실행은 별도 축이며, preview 검증이나 배포 파일 일치로 대신 완료 판정하지 않는다. 데이터·캘린더·권한 및 저장 계약은 변경하지 않는다.

## 최종 개발 검사

- `npm run typecheck` 및 `npm run build:vite` 통과. 모든 코드 수정이 끝난 뒤 실행했다.
- 정식 빌드와 같은 9개 시험 묶음 총 2,333개 통과, 실패·취소·건너뜀 0. 간트 275개(실제 PGlite SQL 계약 포함), 캘린더 958개, 자동 업데이트 30개 포함.
- 업데이트 안내는 182개 버전·573개 항목이며 이전 181개 버전의 내용을 보존했다.
- 배포는 PR 병합 커밋의 별도 깨끗한 워크트리에서 `npm run build`로 설치 파일을 생성하고, 전체 파일 해시 검증 뒤 manifest를 마지막에 게시한다. 병합·배포 최종 증거는 PR에 기록한다.
