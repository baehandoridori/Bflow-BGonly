# 간트·캘린더 사용성 및 연동 점검

## 요청과 완료 조건

1. 간트와 캘린더의 생성·편집·삭제·완료·동시 수정·권한·연동 일정을 로컬 심층 리뷰하고 문제를 재현해 수정한다.
2. 같은 연결 일정의 색상 규칙을 통일하고, 일반 캘린더 색상과 상속 규칙을 보존한다.
3. 선택창과 툴팁의 공용 디자인·키보드·포커스·작은 창 동작을 점검한다.
4. OmniPlan의 계층 목록·선택 상세·일정 탐색 흐름을 참고해 간트 정렬과 사용성을 검토한다. 이전/다음 월, 오늘 복귀, 주차 표시를 추가한다.
5. 라이트/다크 모드에서 간트·캘린더 주요 화면 및 메뉴·선택·완료·오류의 글자 가시성을 확인한다.
6. 실제 로그인한 preview 조작, 의미 있는 회귀 시험, 독립 로컬 리뷰, typecheck, build:vite, 정확한 merge의 정식 Windows build를 통과한다.
7. 필요한 SQL을 검증·적용하고 manifest-last 배포, 전체 파일 SHA-256·버전·과거 노트 보존 검증을 완료한다.
8. 표준어 보고서에서 수정 전/후, 확인한 범위, 증거, 남은 개선 제안과 우선순위를 구분한다. 구현되지 않은 제안을 완료로 표시하지 않는다.

## 진행 방식

- 기준: origin/main 226319e963351f0e57ecaa922ab0861e37ca38ff (v1.114.0), 원래 dirty checkout 보존.
- 날짜축/탐색, 공용 UI/라이트 모드, 캘린더 데이터 연동을 분담하고 부모 작업은 통합·실제 브라우저 검증·보고서·릴리스를 맡는다.
- 보고된 결함마다 근거와 동작 회귀를 남긴다. 레이아웃·표현은 실제 DOM/화면으로 확인하고 데이터 경계는 행위/DB 시험으로 검증한다.
- 운영 계정 데이터는 직접 시험 대상으로 수정하지 않는다. 운영 DB 검증은 임시 fixture를 BEGIN/ROLLBACK 안에서만 사용한다.

## 비교 기준

- [OmniPlan 4.5.5 Gantt View](https://support.omnigroup.com/documentation/omniplan/mac/4.5.5/en/gantt-view/): 계층 목록과 차트, 그룹 범위, 작업 순서, 일정 탐색.
- [OmniPlan 4.5.5 Task Inspector](https://support.omnigroup.com/documentation/omniplan/mac/4.5.5/en/the-task-inspector/): 선택한 작업의 제목·기간·진행·연결 정보를 문맥에 맞게 편집.
- 위 기능을 그대로 복제하지 않고 B flow의 프로젝트·씬·공유 권한과 기존 사용 흐름에 맞춰 평가한다.

## 완료 감사

최종 보고서의 요구사항 표에 현재 코드/테스트/브라우저/서버/배포 증거를 연결한다. 일부 테스트의 성공만으로 전체 캘린더 또는 라이트 모드가 무결하다고 주장하지 않는다.
