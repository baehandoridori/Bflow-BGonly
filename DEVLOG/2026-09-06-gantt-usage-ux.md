# 간트 실사용 개선 — v1.113.0

완료한 작업이 사라져 보이고 폴더·프로젝트·그룹의 역할과 삭제 위치가 불분명하다는 사용자 피드백을 반영했다. 사용자가 요청한 그랩은 작업 날짜 이동이 아니라 차트 화면 이동이다.

## 동작

- 폴더 → 프로젝트 → 그룹(선택) → 작업/마일스톤. 폴더는 정리·공유 단위이며 완료 상태가 없다.
- 전체 보기가 기본이다. 완료 항목은 체크 표시와 함께 원래 위치에 남는다. 진행 중/완료 보기를 명시적으로 선택할 수 있고 필터에 맞는 작업의 상위 맥락을 유지한다.
- 프로젝트 완료는 하위 작업도 완료한다. 프로젝트 다시 열기는 개별 작업의 완료·진행률을 보존한다. 그룹 완료/다시 열기는 하위 범위를 안내한 뒤 적용한다.
- 그룹 완료와 진행률은 동일한 공용 하위 집계로 계산한다. 미완료 빈 하위 그룹도 포함한다. 씬 자동 진행률의 표시값은 편집용 저장 원본과 분리한다.
- 프로젝트·그룹·작업의 ⋯/우클릭 메뉴와 상세에서 완료와 삭제를 구분한다. 폴더는 안의 프로젝트를 먼저 삭제한 뒤 폴더 설정에서 삭제한다. `requireEmpty:true`가 서버에서도 동시 추가를 차단한다.
- 기본 빈 곳 드래그는 화면 이동이다. 작업 만들기 모드는 빈 날짜 범위 생성, 작업 막대는 날짜 이동, 양 끝은 기간 변경이다. Space 임시 화면 이동과 포인터 취소·캡처 해제·창 전환 복구를 제공한다.

## 구현과 데이터 경계

- `GanttCanvas.tsx`: 상태 필터, 상위 맥락, 완료 배지, 행 메뉴, pan/create/edit 포인터 상태와 ID 검사.
- `domain.ts`: `isTaskComplete`, `taskProgress` 공용 집계. 프로젝트 종료는 명시적으로 유지하며 작업 재개/추가는 상위 완료 상태를 해제한다.
- `GanttView.tsx`, `GanttDialogs.tsx`, `GanttInspector.tsx`: 전체 기본 보기, 상세 유지, 정확한 대상 삭제, 빈 폴더 삭제, 계층 안내와 표시용 진행률.
- 새 SQL이나 운영 DB 변경은 없다. 기존 권한, revision CAS, 낙관적 반영→정본 저장→실패 롤백, undo/redo 계약을 유지한다.

## 실제 프리뷰 인수

`http://127.0.0.1:5196/?preview=1`에 지정된 프리뷰 계정으로 로그인하고 검증용 폴더·프로젝트·작업을 생성했다.

1. 완료 후 상세 유지, 진행률 100%, 다시 열기 표시와 전체 차트의 완료 배지 확인. 새로고침 뒤에도 기록 유지.
2. 진행 중 필터에서 완료 작업 제외, 완료 필터에서 상위 프로젝트와 완료 작업 함께 표시.
3. 기본 빈 곳 드래그: 가로 위치 720→1000, 작업 2개 및 이름·기간 동일.
4. 전체 15개 행에서 양축 이동: 가로 440.6667→550.6667, 세로 0→210, 행 수 동일.
5. 작업 만들기 모드의 범위 드래그: 그룹 안에 2026-09-09~11 작업 1개 생성. 소속 경로 확인.
6. 작업 막대 이동: 2026-09-10~12로 이동, 3일 기간 유지.
7. 그룹 완료 후 하위 작업을 다시 열면 그룹도 진행 중. 다른 완료 작업은 유지.
8. 그룹 삭제 범위 2개 안내, 삭제 후 하위 2개 제거, 실행 취소 후 2개 복원.
9. 프로젝트 완료 후 다시 열어도 개별 작업·그룹 완료 기록 유지.
10. 작업 삭제와 프로젝트 삭제가 각 메뉴 대상에 적용됨.
11. 프로젝트가 있는 폴더는 개수 안내와 삭제 비활성화. 빈 폴더는 삭제 확인 제공.
12. 빈 폴더 삭제→실행 취소→다시 실행에서 메뉴 개수 0→1→0. 검증용 프로젝트·폴더 정리 완료.

Space 조합·권한 회수·동시 변경은 자동 핸들러/데이터 시험으로 확인했다. 이번 UI 인수는 브라우저 테스트 모드이며 설치된 Electron 앱의 인수와 구분한다. 정식 설치 파일과 공유 드라이브 배포 결과는 PR 릴리스 기록 및 별도 산출물 JSON에서 확인한다.
