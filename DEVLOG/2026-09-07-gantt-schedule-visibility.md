# 간트 일정 이동과 진행 표시 개선

## 변경 범위

- 그룹의 위·좌·우 테두리 안에 진행률 채움을 복원하고, 진행률 증가 때 차트와 상세 편집기 테두리가 짧게 반응한다. 동작 줄이기 설정에서는 효과를 생략한다.
- 프로젝트는 아이콘과 큰 굵은 이름, 그룹은 접기 버튼과 중간 굵기, 작업은 기본 굵기로 구분한다. 완료는 체크가 있는 버튼으로 보이며 상세창에서 다시 열 수 있다.
- 차트 이름의 호버와 행 옆 메뉴 버튼을 제거한다. 실제 막대에서 세부정보·전체 메모를 열며, F2로 스크롤 영역에 진입하고 Escape로 해당 막대에 돌아온다. 우클릭과 상세 편집은 유지한다.
- 그룹 날짜 이동은 접힘·필터와 관계없이 모든 하위 그룹·작업·완료 작업을 한 번에 저장한다. 자동 일정이 포함되면 확인 후 수동으로 전환하되 선행 연결을 유지한다. 프로젝트 단위 저장 실패는 전체 롤백한다.
- 새 프로젝트와 최상위 그룹은 기존 팔레트에서 구별되는 기본색을 저장한다. 하위 그룹·작업은 부모 색을 상속하고 캘린더도 같은 정본 색을 사용한다. 기존 사용자 지정 색과 상속 선택은 보존한다.
- 각 막대 오른쪽에 기간을 표시한다. 표시 메뉴에서 오늘 세로선과 남은 일수를 선택하며, 날짜는 자정·창 복귀 시 갱신한다. 월 길이를 가정하지 않고 일 단위, 시간 일정은 일·시·분 단위를 사용한다.

## 데이터와 검증 경계

`shiftTaskSubtree`는 정본 프로젝트를 복제하고 후손의 날짜를 같은 간격으로 이동한 뒤 기존 일정 계산을 적용한다. Canvas의 임시 진행률·드래그 데이터는 저장하지 않는다. View는 상세 초안 저장과 확인창 이후에도 계정·편집 권한·revision·연결 캘린더를 재확인한다. 기존 CAS, undo/redo와 calendar projection 계약을 유지한다.

운영 DB 정책·schema·RPC·인증 코드는 변경하지 않았다. 현재 서버 세션 경계와 별도 기존 사용자 관리 위험은 [읽기 전용 보안 점검](../docs/verification/2026-09-07-gantt-auth-boundary-audit.md)에 기록했다. 이 UI 릴리스가 앱 전체의 기존 보안 문제를 해결했다는 의미는 아니다.

## 확인한 사용 흐름

2026-09-07 로컬 renderer preview, 테스트 로그인 배한솔, 별도 포트 5201에서 수행했다.

- 1280×720 어두운 테마: 진행률 0→68 즉시 차트 반영·자동 저장, 그룹 진행률 채움, 완료 후 작업 유지와 체크 버튼.
- 실제 포인터 드래그로 그룹을 +2일 이동, 자동 일정 확인 후 완료 작업 시작·종료가 2026-09-07→09-09로 함께 이동.
- 기간과 남은 일수 표시 켜기. 완료된 일정도 기간을 유지하고 오늘 기준 날짜를 표시.
- 막대 F2로 60줄 메모의 마지막 문구까지 존재함을 확인, Escape 후 원래 막대에 포커스 복귀.
- 1024×640 밝은 테마: 긴 제목 여러 줄 표시(내용 높이와 입력 높이 일치), 상세 하단 완료·삭제 버튼이 화면 안에 유지됨. 사이드바를 접으면 차트 폭 확보.
- 막대 옆 이름 보기와 전체 일정 맞춤에서 왼쪽 이름이 잘리는 문제를 발견했다. 현재 스크롤 좌표와 이름·기간의 실제 폭을 반영하도록 수정 후 1024×640에서 모든 이름이 화면 안에 들어오는 것을 확인했다. 맞춤·하루 미만 이동·확대 회귀 시험도 추가했다.
- 앱의 아주 큰 글씨(1.2배)와 캡션 1.4배 설정에서 완료 문구가 필요한 경우 두 줄로 감싸지고 삭제 버튼도 패널 안에 남는 것을 직접 확인했다. 검사 후 기본 글씨 설정으로 복원했다.

포인터 hover 지연·ghost 중간 좌표·필터된 중첩 후손·색상 projection·동시 수정 경계는 관련 자동 행동 테스트로 별도 확인한다. 이번 기록은 새 Windows 설치본이나 다중 운영 계정의 실제 조작 증거가 아니다.
