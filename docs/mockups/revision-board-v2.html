이미지 있을 때 vs 없을 때
  • · 씬별/에피소드별: 카드 좌측 128×80 썸네일 영역. 없으면 그 영역 자체가 사라지고 본문이 풀 폭. "— 이미지 없음" 안내 (메타 끝)
  • · 진행률별(칸반): 카드 상단 풀 폭 80px 썸네일. 없으면 영역 자체 생략, 카드가 더 컴팩트해짐
  • · 우측 디테일 패널: 첨부 이미지가 있을 때만 그리드 표시
한솔님 요구사항 매핑
  • · "내가 보낸 / 받은 한눈에" → 최상단 페르소나 탭 + 받은 것 5개 강조 뱃지
  • · "씬별 / 에피소드별 / 진행률별" → 그룹화 토글 3종 (한솔 명시 그대로)
  • · "필요시 씬 상세로" → 씬 헤더 우측 + 카드 호버 액션 + 디테일 패널 상단 모두 ↗ 버튼
  • · "쉽게 관리" → 우측 디테일 패널에서 인라인 댓글 + 상태 변경
