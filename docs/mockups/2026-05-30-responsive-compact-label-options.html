전역 반응형 라벨 폴리싱 시안

좁은 창에서 버튼 라벨이 말줄임 또는 세로 배치로 무너지는 문제를 전역 규칙으로 정리하는 시안입니다. 실제 데이터 텍스트는 보존하고, 조작 버튼과 상태 칩만 단계적으로 아이콘화합니다.

방향 선택

각 방향을 누르고, 오른쪽에서 폭을 바꿔 보세요.

조작 버튼: 좁아지면 아이콘만 남기고 tooltip/aria-label로 의미를 보존합니다.
실제 데이터: 씬명, 담당자, 메모, 댓글 본문은 임의 아이콘화하지 않습니다.
시트 헤더: 아이콘보다 짧은 코드 라벨을 씁니다. 예: Storyboard는 SB, Acting은 ACT.
너무 좁은 조작 묶음은 C안처럼 더보기로 흡수할 수 있습니다.
