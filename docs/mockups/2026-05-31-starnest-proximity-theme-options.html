Plexus / StarNest 선택형 거리 기반 카드 반응

설정창 시안: 배경 아트 엔진 선택

현재 플렉서스가 쓰이는 위치에서 StarNest를 같은 자리의 대체 옵션으로 선택합니다.

StarNest 깊은 우주감, 중심부 회전, 은은한 광량. 로그인과 대시보드에 가장 잘 맞는 후보.
Plexus 기존 점과 선 기반 배경. 현재 톤 유지가 가장 쉽고 성능 예측이 안정적.
배경 아트 끄기 저사양 PC나 집중 모드에서 조명 배경만 남기는 선택지.
StarNest 플렉서스와 같은 자리에 들어가는 우주형 배경 엔진. 테마 색을 받아 은은하게 변형됩니다.

반응 방식 가까운 카드만 크게 반응하고, 주변 카드는 거리만큼 작게 반응합니다. 클릭 기능과 선택 상태는 그대로 유지하는 방향입니다.

적용 방향 후보

지금 단계에서는 구현이 아니라 방향 선택입니다. 원하는 방향을 골라주면 다음 질문을 이어가겠습니다.

A

권장: 배경 엔진 선택 + 절제된 proximity

설정의 효과 섹션에서 Plexus / StarNest / OFF를 선택합니다. 컴포지팅 카드는 가까운 카드만 은은하게 반응해 업무 화면의 안정감을 지킵니다.

B

몰입형: StarNest 중심 테마

StarNest를 하나의 테마 분위기로 키웁니다. 로그인과 대시보드에서 더 강하게 보이고, 컴포지팅 카드도 더 생동감 있게 움직입니다.

C

보수형: 기존 플렉서스 유지, 카드만 개선

StarNest는 나중으로 미루고 컴포지팅 카드 proximity만 먼저 넣습니다. 변경 범위가 가장 작지만 새 테마의 체감은 약합니다.

구현 시에는 움직임 줄이기 설정(prefers-reduced-motion), 저사양 PC용 OFF/약 모드, 설정 저장(preferences.json)을 같이 고려해야 합니다.
