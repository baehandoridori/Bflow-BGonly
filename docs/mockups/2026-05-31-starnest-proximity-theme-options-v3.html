현재 정리된 설계 후보

이제 “타임라인 카드 펼침”을 컴포지팅 탐색의 핵심으로 볼지 결정하면 됩니다.

A

권장: 타임라인 바 스캔 → 1~2개 카드 미리보기

파트 바는 전체 위치와 진행 색상을 보여주고, 마우스 위치에 맞는 씬 카드만 짧게 띄웁니다. 60개 씬이 있어도 화면을 덮지 않습니다.

B

더 강하게: 주변 씬 3~5개까지 노출

탐색 속도는 빨라지지만 카드가 많아질수록 타임라인의 장점이 흐려집니다. 프리뷰/검토 모드 전용에 더 가깝습니다.

C

보수형: 카드 그리드만 proximity

기존 카드 뷰의 dock-lift만 개선합니다. 구현 위험은 작지만 “타임라인에서 빠르게 씬 찾기” 경험은 약합니다.

실제 구현 시에는 기존 `TimelinePanel`의 part hover에 “파트 내부 x좌표 → 씬 인덱스” 계산을 추가하면 됩니다. 새로 필요한 건 “현재 스캔 위치 주변 1~2개 카드 레이어”, “카드 핀 유지”, “카드 거리 기반 transform”입니다.
