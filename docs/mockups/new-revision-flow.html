한솔님 피드백 반영
  • · 우측 패널 시안 제거 — 중앙 모달로 확정
  • · 에피소드 칩에서 EP01 prefix 제거 — 제목만 ("두근두근 첫 등교")
  • · 씬 선택을 검색 가능한 드롭다운 + 선택 칩으로 변경 (그리드 → 사람 검색 패턴)
  • · 알림 받을 사람 — 자동 체크된 사람이 뱃지로 즉시 표시 (모달 열리자마자)
씬 선택 UX 흐름
  • · input 클릭 → 전체 씬 드롭다운 펼침 (스크롤 가능)
  • · 검색어 입력 → 자동완성 필터링 (씬번호·메모 매칭)
  • · 항목 클릭 → 검색 input 자리에 선택 칩 + 메모 표시
  • · 칩의 × 클릭 → 다시 검색 모드
  • · 미해결 카운트는 검색 결과 행 + 선택 칩에 같이 노출 (선택 전 컨텍스트)
  • · 상단 토글로 "검색 중 / 선택됨" 두 상태 직접 비교 가능
