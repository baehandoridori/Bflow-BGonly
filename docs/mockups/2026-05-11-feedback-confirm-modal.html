시안의 핵심 동작

  • ① 피드백 대기 칩을 누르면 (카드/시트/상세 모달 어디서든) 이 모달이 먼저 뜸. 모달을 거치지 않으면 상태는 안 바뀜.
  • ② 액팅 검수자 풀 멤버 전원이 기본 체크. 빼고 싶은 사람은 줄을 눌러 체크 해제.
  • ③ 추가 멘션 (선택) 영역에 컴포지터, 그 씬의 BG 담당자가 후보로 자동 노출. 더 필요하면 "+ 다른 팀원 검색"으로 사내 누구든 추가 가능.
  • ④ 푸터 3 버튼:
    • • 취소 — 상태도 변경 안 함, 모달 닫힘. (잘못 클릭 방지 1차)
    • • 알림 없이 상태만 변경 — 칩만 피드백 대기 N차로 바뀌고 아무에게도 알림 안 감.
    • • 알림 보내기 (N명) — 상태 변경 + 선택된 N명에게 토스트/인앱 알림.
  • ⑤ "다음에 이 씬에 다시 피드백 대기 누를 때 마지막 선택을 기억" 옵션도 고려 가능 (한솔님 의견 필요).

한솔님 — 마지막 디테일 확인

모양은 위 시안대로 가도 OK 인지, 그리고 아래 두 가지 작은 결정을 알려주세요:

  1. "추가 멘션" 후보에 자동으로 무엇이 보이게 할까요?
    • (a) 컴포지터 풀 + 그 씬 BG 담당 (시안과 동일)
    • (b) 비워두고 사용자가 직접 "+ 검색" 으로만 추가
  2. "알림 없이 상태만 변경" 버튼을 둘까요?
    • (a) 둠 — 잘못 눌렀거나 알림이 부담스러울 때 유용 (시안과 동일)
    • (b) 없앰 — 피드백 대기는 항상 알림이 가도록 강제 (책임 명확)
