StarNest는 원본 Star Nest 셰이더 수식을 WebGL로 옮긴 느낌에 가깝게 다시 만들었습니다. 컴포지팅은 파트별 타임라인 바를 호버하면 해당 파트 씬 카드가 위로 순차 등장하고, 카드 위로 올라가면 proximity 반응과 핀 동작이 이어지는 흐름입니다.

현재 정리된 설계 후보

이제 “타임라인 카드 펼침”을 컴포지팅 탐색의 핵심으로 볼지 결정하면 됩니다.

A

권장: 타임라인 바 → 카드 팬아웃 + 카드 proximity

파트 바는 전체 위치와 진행 색상을 보여주고, 호버 시 해당 파트 씬 카드를 위로 펼칩니다. 카드 위에서 핀/상세 열기까지 이어집니다.

B

더 강하게: 바 위에 카드가 크게 떠오름

레퍼런스처럼 더 많이 움직이고 커지는 방식입니다. 생동감은 좋지만 업무 화면에서는 산만할 수 있습니다.

C

보수형: 카드 그리드만 proximity

기존 카드 뷰의 dock-lift만 개선합니다. 구현 위험은 작지만 사용자가 말한 “타임라인에서 카드 찾기” 경험은 약합니다.

실제 구현 시에는 기존 `hoveredPart` 상태와 `TimelinePanel`의 part hover를 재사용할 수 있습니다. 새로 필요한 건 “호버 중인 파트의 씬 카드 팬아웃 레이어”와 “거리 기반 카드 transform”입니다.
