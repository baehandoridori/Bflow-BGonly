묶음 규칙 (확정)
  • 같은 userId 연속이면 무제한 묶음 (시간 무관)
  • 다른 사용자가 쓰면 끊김 (필수)
  • 시스템 활동 이벤트(단계 변경, 메모 수정 등)가 사이에 있으면 끊김 (선택 — 추천)
  • 묶인 답글은 기본 시간 숨김, 호버 시 좌측에 시간 표시
  • 이름·아바타·날짜 헤더는 첫 댓글에만 노출

안 본 알림 — 시각적 강조 (2단계)

헤더 벨에 그라데이션 + 부드러운 펄스. 멘션은 액센트 색 좌측 바 + @ 배지, 자동 알림은 회색 좌측 바 + 텍스트만으로 시각 차별화.

알림 항목 — 상태별 시각차

멘션 (Mentioned)
  • 좌측 바: 액센트 색 (rgb(--accent))
  • 제목 행 우측에 @ 배지 (배경: 액센트 소프트)
  • 본문은 굵게 + 풀 컬러 텍스트
  • 전체 카드 배경 액센트 0.10 alpha
자동 알림 (씬 작업자)
  • 좌측 바: 회색 (border-2)
  • 제목/본문은 일반 두께
  • 전체 카드 배경 accent 0.04 alpha (살짝 톤만)
  • 아이콘 색은 type 색 (댓글: accent, 변경: 파랑)
읽음 (Read)
  • 좌측 바: 투명
  • 제목/본문 70% opacity
  • 호버 시만 살짝 카드 배경 변화
