1. 전체 완료 표시 + 마지막 동작 취소

완료가 뜬 직후, 사용자가 방금 누른 체크만 되돌리는 안입니다.
현재 화면의 모든 씬이 완료되었습니다 방금 누른 마지막 체크: EP03 A 014 · PNG 완료
추천: 마지막 체크 1개만 되돌리기

실수 복구가 빠르고, 다른 사람의 변경이나 예전 작업까지 되돌릴 위험이 낮습니다.

넓은 취소: 마지막 일괄 작업 되돌리기

여러 씬을 한 번에 완료한 경우 유용하지만, 실패/부분 저장 처리까지 설계해야 합니다.

단순 안내: 창만 닫기

안전하지만 사용자가 다시 뒤로 가서 체크를 찾아 꺼야 해서 문제 해결력이 낮습니다.
