상세 모달 액팅 칩 — "작..." 잘림 해결안

상세 모달의 액팅 영역(폭 280px)에서 활성 칩 안 차수 카운터가 들어가면 라벨이 잘리는 문제. 아래는 4개 시안. 한솔님이 명시 — "피드백 대기는 숫자 없이 표기 OK" 도 반영.

현재 (문제)

활성 칩 안 차수 inline + flex-1 균등

활성 칩이 라벨 + 차수 ▲▾ 둘 다 안에 넣다 보니 좁은 모달에서 "작..." 으로 잘림.

활성 칩만 넓게 (flex-grow 2)

기본 모양 유지하면서 활성 칩만 더 큰 공간 점유. 라벨 + 차수 둘 다 들어감.

시안 B

차수를 칩 위 별도 영역으로

칩은 라벨만 균등 분할. 활성 칩이 작업중/피드백 대기일 때만 위쪽에 "작업중 2차 ▾▴" 작은 라벨이 보임.

한솔님 — 어느 시안이 좋으세요?

  • • A: 가장 변경 적음. 활성 칩만 살짝 넓어짐. 현재와 거의 동일
  • • B: 차수가 칩 위 헤더 영역에 큰 글자로. 한 줄 추가
  • • C: 피드백 차수 없앰 + 작업중만 inline 차수 + 활성 grow. 한솔님 룰 직설적
  • • D: 칩 행 오른쪽에 차수 색박스 별도. 디자인 새로움, 폭 안정
