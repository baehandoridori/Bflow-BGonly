전체 씬 조작
여러 씬에 같은 단계 체크를 적용할 때는 선택된 씬의 모든 담당자 슬롯에 동일 단계가 적용됩니다. 단, 일부 담당자만 바꾸는 옵션은 별도 토글로 분리합니다.
개별 조작
카드/시트에서 사람 이름 옆 작은 단계 칩을 누르면 해당 담당자 슬롯만 바뀝니다. 씬 전체 단계 칩을 누르면 두 사람 모두에 적용됩니다.
계산 방식
2명 담당이면 총 단계는 8개입니다. 두 사람의 완료 단계를 합산해 씬 퍼센트를 계산합니다.
추천 방향
카드는 “씬 상태를 빠르게 읽는 화면”이라 합산 진행률을 우선합니다.
시트는 “정확히 조작하는 화면”이라 사람별 단계 수를 노출하는 편이 안전합니다.
