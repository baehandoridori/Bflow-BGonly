한
→ 여기서 적으면 일반 씬 댓글로 (라벨 없음). 리비전 댓글은 카드 안에서 적기.
데이터 모델 (단순화)
모든 댓글은 같은 곳에 저장되고, 그 중 일부에는 "어느 리비전과 연결되어 있는가" 표시(re3 같은)가 붙어요. 그 표시가 있는 댓글은 → 리비전 카드 안 + 씬 댓글 패널 양쪽에 표시. 표시 없는 건 → 씬 댓글 패널에만 표시.
상호작용
  • · 우측 패널의 re3 배지 클릭 → 좌측 카드로 스크롤 + 1.2초 강조 애니메이션
  • · "re만" 버튼 클릭 → 일반 씬 댓글 숨김, re 라벨 댓글만 표시
  • · 카드 안 입력은 자동으로 그 카드의 [re#] 맥락이 붙음
