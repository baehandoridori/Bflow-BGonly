v2 규칙

  • createPortal(document.body) — CommentPanel/모달의 stacking context 무관
  • z-index 99999 — 사이드바(100), 모달(50), 어떤 컴포넌트보다 위
  • 레이아웃: 헤더 (씬·작성자·시간·N/M·본문) / 메인 이미지 (70% 폭) / 하단 썸네일 strip
  • 썸네일 strip — 모든 이미지 가로 나열, 현재 active 는 보라 outline + 1.05 scale, hover 는 옅은 outline
  • 썸네일 클릭으로 직접 이동 + 키보드 ← → 순환 + ESC 닫기 (capture stage stopPropagation 으로 모달 prev/next 충돌 X)
  • 이미지 1장이면 좌우 화살표 + 썸네일 strip 모두 숨김 (단일 이미지는 v1.24.0 그대로)
  • prefers-reduced-motion 시 transition 제거

"이미지 N개인데 1/1로 보임" 가설

  1. 팀원 PC가 아직 v1.23.5 — v1.23.5의 라이트박스는 단일 이미지만 지원 (배열 미지원). v1.24.0 받으면 자동 해결.
  2. 댓글 묶음 표시 착시 — 같은 사용자가 *4번*에 걸쳐 1개씩 첨부 → Slack 식 묶음으로 한 댓글처럼 보이지만 실제론 4개 분리된 댓글, 각자 1개 이미지. 라이트박스는 1개 댓글 = 1개 이미지 정확히 표시.
  3. 한 번에 N개 첨부했는데 1로 저장 — 데이터 자체 버그 (가능성 낮음). supabase 직접 query 로 검증 필요.

확인 필요: 한솔 PC(v1.24.0)에서 새 댓글에 이미지 N개 한 번에 첨부 → grid 에 N개 보이는지 → 클릭 시 라이트박스가 N/N 으로 보이는지.
