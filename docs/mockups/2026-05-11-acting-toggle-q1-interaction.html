Q1 / 6 · 토글 인터랙션 모델

액팅 씬 토글을 화면에서 어떻게 만지면 좋을까요?

상태 4개(대기 / 작업중 / 피드백 대기 / 완료) + 차수(1차, 2차…)를 한 줄에 담는 방식. 세 가지 시안 중에 한솔님 머릿속 그림과 가장 가까운 걸 골라주세요.
아래 칩/버튼은 실제로 눌러볼 수 있습니다.

옵션 A

칩 4개 라디오 + 활성 칩 안에 차수 +/−

네 가지 상태가 항상 보이고, 하나만 색이 들어옵니다. 작업중·피드백 대기에는 칩 안쪽에 작은 ▲▼ 가 붙어 차수를 조정.

미리보기 — 씬 행
001 SC_001 담당 · 김아무
대기 작업중 1차 피드백 대기 1차 완료
002 SC_002 담당 · 이아무
대기 작업중 2차 피드백 대기 2차 완료
003 SC_003 담당 · 박아무
대기 작업중 1차 피드백 대기 1차 완료
좋은 점
  • 네 상태를 한눈에 — 클릭 한 번으로 어느 상태로든 점프
  • 차수 ▲▼ 가 활성 칩 안에 들어가서 시선 흐트러짐 적음
  • 현재 BG의 LO/완료/검수/PNG 와 모양이 비슷해 학습 부담 적음
아쉬운 점
  • 칩 4개 + 카운터까지 합쳐 가로 폭이 가장 넓음 (좁은 화면에선 줄바꿈 가능)
  • 대기/완료 같은 정적 상태에는 들어가지 않는 ▲▼ 가 시각적으로 비대칭
옵션 B

현재 상태 칩 1개 + 좌우 ◀▶ 단계 이동

지금 어느 상태인지만 큼지막한 칩으로. 옆 ◀▶ 으로 앞/뒤 단계로 보냄. "피드백 대기"로 갈 때 자동으로 +1차, 다시 작업중으로 갈 때도 자동 +1차. 차수 수동 조정은 칩을 우클릭하거나 길게 눌렀을 때 펼쳐지는 ▲▼.

미리보기 — 씬 행
001 SC_001 담당 · 김아무
작업중 1차
002 SC_002 담당 · 이아무
피드백 대기 2차
003 SC_003 담당 · 박아무
완료
좋은 점
  • 한 줄에 들어가는 폭이 가장 좁음 — 씬 목록이 빽빽해도 깔끔
  • "한 단계 진행 / 되돌리기" 흐름이 자연스러움 (작업중 → 피드백 = ▶ 한 번)
  • 피드백 ↔ 작업중 왕복마다 자동으로 +1차 → 손이 덜 감
아쉬운 점
  • 지금 상태 외엔 안 보여서 "지금 몇 단계지?" 한 번 더 인지 부담
  • 중간 상태를 건너뛰려면 ▶ 여러 번 — 직접 점프가 어려움
  • 차수 수동 조정이 숨겨져 있어 초보자에게는 보이지 않음
옵션 C

가로 스테퍼 트랙 + 차수 배지

네 단계를 가로 선으로 잇고 점으로 표시. 현재 위치만 색이 들어오고, 작업중·피드백 대기 점 위에 작은 "1차/2차" 배지. 점을 직접 클릭해서 어느 단계로든 이동. 점 옆 ▲▼ 으로 차수 조정.

좋은 점
  • "이 씬이 작업 흐름의 어디쯤 와 있나" 가 시각적으로 가장 명확
  • 작업중·피드백 대기 차수가 항상 보임 — 1차/2차/3차 누적이 한눈에
  • 점을 클릭하면 그 단계로 직접 이동 (옵션 A와 같은 자유도)
아쉬운 점
  • 가로 폭이 옵션 A와 비슷하게 넓고, 점·라벨이 작아져 클릭이 살짝 까다로움
  • 차수 ▲▼ 인터랙션을 어디에 둘지 디테일이 더 필요 (점 위 호버? 우클릭?)
  • 시각적 요소가 가장 많아 정보 밀도가 높은 씬 행에선 부담될 수 있음

한솔님께 — 질문

세 시안 중 어느 것이 가장 자연스러우신가요? 또는 "A 기본 + B/C 의 ○○ 요소만" 같은 조합도 환영입니다.

참고로 B flow 의 씬 한 행은 보통 좁은 공간에 많은 정보가 들어가는데(번호·ID·담당·메모·이미지·각종 토글), 이 토글 영역이 어느 정도 폭을 차지해도 괜찮은지도 같이 떠올려 보시면 좋습니다.
