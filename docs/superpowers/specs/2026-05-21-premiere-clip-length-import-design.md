## 1. 배경

한솔님 팀은 공용으로 쓰는 프리미어(.prproj) 파일에서 V1 (비디오 트랙 1) 에 씬 클립들을 순서대로 배치해 작업한다. 각 클립의 이름이 sceneId 와 매칭되고 (예: "a005"), 클립 길이 = 그 씬의 실제 길이.

컴포지팅 대시보드의 AE 타임라인 패널이 진짜 시간축으로 작동하려면 씬마다 `duration_frames` 가 필요하다. 매번 수동 입력은 부담. 프리미어 파일에서 자동 추출이 자연스러움.

## 2. 목표

- 한솔님이 디렉토리에서 .prproj 파일 선택
- V1 트랙의 클립 이름과 길이 자동 파싱
- 매칭되는 scene 의 `duration_frames` 자동 채움
- 충돌/누락 케이스 보고
- 수동 수정 path 유지 (씬 상세 모달에서 직접 편집)

## 3. 미정 사항 (본격 설계 시 결정)

- .prproj 파일 포맷 파싱 방법 (XML 추출 / Adobe SDK / 제3자 라이브러리)
- 클립 이름 → sceneId 매칭 룰 (정확 매치 / fuzzy / prefix)
- 파트/에피소드 자동 인식 vs 수동 선택
- 진행 UX (드래그&드롭 / 디렉토리 선택 / 결과 미리보기 / 확정 버튼)
- 충돌 해결 UX (이미 길이 있던 씬 덮어쓰기 여부)
- 파일 위치 기억 (다음에 같은 EP 갱신할 때)
- 누가 실행 가능한지 (관리자만 / 컴포지터 / 모두)
