# 캘린더 대규모 개선 디자인 스펙

## Context

ScheduleView(캘린더 탭)의 UX가 구글 캘린더 수준에 못 미침. 이벤트 생성이 모달 의존적이고, 월간 뷰가 화면에 꽉 안 차며, 주간 뷰가 단순 리스트 형태. 우클릭 퀵 편집 없음. 이번 개선으로 구글 캘린더급 인터랙션을 달성.

---

## 1. 전체 레이아웃 (오버레이 스타일)

**핵심 파일**: `src/views/ScheduleView.tsx`

### 구조
```
┌──────────────────────────────────────────────────┐
│ [접힘/펼침 사이드바]  │  메인 캘린더 그리드           │
│                      │                              │
│ 월간뷰: 미니캘린더    │  (이벤트 클릭 시)             │
│ 주간뷰: 주차 리스트   │  ┌──────────────────────┐    │
│                      │  │ 플로팅 사이드패널     │    │
│ (기본 접힘 40px)     │  │ (글래스모피즘)        │    │
│ (펼침 시 180px)      │  └──────────────────────┘    │
└──────────────────────────────────────────────────┘
```

- **좌측 사이드바**: 기본 접힘(40px 아이콘), 펼치면 180px
  - 월간 뷰: 미니 캘린더 (오늘 강조, 이벤트 도트)
  - 주간 뷰: 주차 리스트 (1주차~5주차 세로 나열, 활성 주 하이라이트, 이벤트 색상 도트)
  - 접기/펼치기 애니메이션: 0.25s, `cubic-bezier(0.16, 1, 0.3, 1)`
- **메인 영역**: 나머지 전체 공간 사용
- **우측 사이드패널**: 오버레이로 메인 위에 플로팅
  - `backdrop-filter: blur(12px)`, `background: rgba(26,29,39,0.95)`
  - `box-shadow: -8px 0 24px rgba(0,0,0,0.4)`
  - 슬라이드 인: `initial={{ x: 300, opacity: 0 }}`, 0.25s spring

## 2. 월간 뷰 — 화면 꽉 차게 + 동적 행

**현재 문제**: 고정 6행 42칸 → 4~5주 월에 빈 행, 화면 아래 잘림

### 해결
- 해당 월의 실제 주 수(4/5/6)에 따라 `grid-template-rows: repeat(N, 1fr)` 동적 설정
- 남은 공간을 `flex: 1`로 그리드에 배분 → 항상 화면 꽉 참
- 현재 주 행: `background: rgba(108,92,231,0.05)`, 보더 살짝 밝게

### 월간 뷰 휠 스크롤 (주 포커스)
- **동작**: 월간 그리드 위에서 마우스 휠 → 활성 주 이동 (현재 월 내 주차만 순환, 월 경계 넘지 않음)
- **시각 효과**: 활성 주 행의 배경이 `rgba(108,92,231,0.08)`로 강조, 나머지 행은 `opacity: 0.5`로 디밍
- **애니메이션**: `0.3s cubic-bezier(0.16, 1, 0.3, 1)` — 행 배경/투명도 전환
- **디바운스**: 150ms (주간 뷰와 동일)
- **기존 현재-주 하이라이트와 관계**: 휠 미사용 시 현재 주가 기본 활성. 휠 조작 시 활성 주가 이동하며 현재 주 하이라이트는 유지(얇은 보더)
- **좌측 미니캘린더 연동**: 활성 주에 해당하는 날짜들이 미니캘린더에서도 하이라이트

## 3. 드래그로 복수 일 이벤트 생성 (구글 캘린더 스타일)

**핵심 파일**: `src/hooks/useCalendarDnD.ts` (확장)

### 흐름
1. 월간 그리드 셀에서 **mousedown** → 드래그 시작
2. 드래그 중: 선택 범위에 `background: rgba(108,92,231,0.15)`, `border: 1px dashed rgba(108,92,231,0.6)` 표시
3. **mouseup** → 툴팁 팝업 열기 (드래그 영역 근처에 포지셔닝)
4. 단일 셀 클릭도 동일 흐름 (시작일=종료일)

### 구현
- `useCalendarDragCreate` 새 훅 생성 (기존 `useCalendarDnD`는 이벤트 이동/리사이즈용)
- 드래그 상태: `{ isDragging, startDate, endDate, anchorElement }`
- 셀에 `data-date` 속성 부여, `document.elementFromPoint()`로 현재 셀 감지
- 텍스트 선택 방지: `user-select: none` during drag

### 엣지 케이스: 주 행 경계 드래그
- 토요일에서 다음 주 월요일로 드래그 시: 날짜 기반으로 연속 범위 계산 (그리드 행과 무관하게 startDate~endDate 사이 모든 셀 하이라이트)
- `elementFromPoint()`가 그리드 밖을 가리킬 경우: 마지막 유효 셀 유지

## 4. 이벤트 생성 툴팁 팝업

**트리거**: 드래그 완료 또는 빈 셀 클릭

### UI
```
┌─────────────────────────┐
│ [제목 추가_________]     │  ← 자동 포커스, 밑줄 인풋
│ 📅 3/18(수) → 3/20(금) 3일│
│ 색상: ● ● ● ● ● ● ● ● ● ●│  ← 10색 팔레트 (선택 시 체크+보더)
│ [저장]  [상세 설정 →]    │
└─────────────────────────┘
```

- **위치**: 드래그 종료 셀 기준 포지셔닝. 우선순위: 아래-중앙 → 위-중앙 → 우측 → 좌측. 화살표 인디케이터 방향도 연동. `ContextMenu.tsx`의 뷰포트 클램핑 패턴 재사용.
- **크기**: 260px 고정 너비
- **스타일**: 글래스모피즘, `border-radius: 12px`, 화살표 인디케이터
- **동작**:
  - 제목 입력 + 색상 선택 → "저장" 클릭 시 즉시 생성
  - "상세 설정" → 사이드패널 열기 (제목/날짜/색상 프리필)
  - 외부 클릭 또는 ESC → 닫기 (이벤트 미생성)
- **기본값**: 색상 = `#6C5CE7` (accent)

## 5. 좌클릭 → 우측 사이드패널 (상세+편집)

> **기존 `EventDetailModal`(ScheduleView.tsx 내 인라인 컴포넌트, ~line 398)을 완전 대체.** 기존 모달은 삭제하고 이 사이드패널로 교체.

**트리거**: 이벤트 바 좌클릭

### UI
- 너비: 280px, 우측에서 슬라이드 인 (오버레이)
- **상단**: 이벤트 제목 + 색상 도트 + 닫기(X)
- **정보 카드**: 날짜범위, D-day, 타입 뱃지, 연결된 EP/파트/씬
- **메모**: 읽기+편집 가능
- **액션 버튼**: 편집(사이드패널 내에서 폼으로 전환) / 씬 확인 / 삭제
- **휴가 이벤트**: "휴가 관리는 휴가 탭에서 관리합니다" 문구 + "휴가 탭으로 이동" 버튼 (→ `setView('vacation')`)
- **편집 모드**: 버튼 클릭 시 같은 패널 내에서 읽기→편집 폼 전환 (추가 모달 안 뜸)

## 6. 우클릭 → 퀵 편집 모달 (2탭)

**트리거**: 이벤트 바 우클릭 (`onContextMenu`)

### UI — 탭 구조
```
┌──────────────────────────┐
│ [🎨 색상]  [📝 일정 편집] │  ← 탭 헤더, 활성 탭 보라 밑줄
├──────────────────────────┤
│                          │
│  (색상 탭 / 편집 탭)      │
│                          │
│  [📋 복사]  [🗑 삭제]     │  ← 퀵 액션
└──────────────────────────┘
```

**색상 탭**:
- 이벤트 제목 + 현재 색상 도트
- 10색 그리드 (5x2, 32px 정사각, 라운드), 선택 시 체크마크 + 보더
- 색상 클릭 → 즉시 반영 (낙관적 업데이트)

**일정 편집 탭**:
- 제목 인풋
- 시작일/종료일 데이트피커
- 타입 세그먼트 (커스텀/에피소드/파트/씬)
- 메모 텍스트에어리어
- 저장 버튼

**공통**:
- 너비: 300px
- 위치: 우클릭 좌표 기준 (뷰포트 밖 시 자동 조정)
- 글래스모피즘 스타일
- 외부 클릭 / ESC → 닫기
- **휴가 이벤트**: 편집 탭 비활성화, "휴가 관리는 휴가 탭에서 관리합니다" 표시

## 7. 주간 뷰 — 휠 스크롤 포커스 (week 뷰 대체)

**기존 week 뷰**(1주 가로 리스트)를 완전 대체

### 구조
```
┌────────────┬──────────────────────────────┐
│ 좌측 사이드바│  메인 영역                    │
│ (주차 리스트)│                              │
│ [1주차]     │  ... 2주 전 (opacity 0.12)    │
│ [2주차]     │  ... 1주 전 (opacity 0.3)     │
│ [3주차] ◀── │  ▶ 3주차 (ACTIVE, 포커스)     │
│ [4주차]     │  ... 1주 후 (opacity 0.3)     │
│ [5주차]     │  ... 2주 후 (opacity 0.12)    │
└────────────┴──────────────────────────────┘
```

### 메인 영역 — 활성 주
- 보더: `1px solid rgba(108,92,231,0.25)`, `border-radius: 12px`
- 배경: `rgba(108,92,231,0.06)`
- 상단: 7일 날짜 그리드 (요일+숫자), 오늘 보라 원형 배경
- 하단: 이벤트 카드 리스트 (좌측 컬러바 3px + 제목 + 날짜 + D-day)
- **빈 상태**: 이벤트 없는 주 → "이번 주 일정이 없습니다" + 연한 캘린더 아이콘, `color: #8B8DA3`

### 비활성 주
| 거리 | opacity | scale | 표시 내용 |
|------|---------|-------|----------|
| ±1주 | 0.3 | 0.97 | 날짜 + 이벤트 바 요약 |
| ±2주+ | 0.12 | 0.94 | 날짜만 |

### 휠 스크롤 동작
- `wheel` 이벤트 → 디바운스 150ms → 위/아래 주 이동
- 애니메이션: `0.4s cubic-bezier(0.16, 1, 0.3, 1)` (spring)
- 모든 주 동시에 translateY + opacity + scale 전환
- 좌측 사이드바도 동기적으로 활성 주 하이라이트 이동

### 좌측 사이드바 — 주차 리스트
- 각 주: 주차 번호 + 날짜 범위 + 미니 날짜 그리드 + 이벤트 색상 도트
- 활성 주: `background: rgba(108,92,231,0.15)`, `border: 1px solid rgba(108,92,231,0.4)`
- 비활성 주: `opacity: 0.5`
- 주차 클릭 → 메인 영역 해당 주로 스크롤 이동

## 8. 휴가 이벤트 문구/동작 변경

**현재**: "휴가 이벤트는 프로필 설정에서 관리됩니다" + 프로필 설정 이동
**변경**: "휴가 관리는 휴가 탭에서 관리합니다" + 휴가 탭 이동

### 변경 포인트
- `ScheduleView.tsx` 내 `EventDetailModal`(인라인 컴포넌트, ~line 398)의 vacation 분기 → 새 사이드패널로 이관
- 문구: `'휴가 관리는 휴가 탭에서 관리합니다'`
- 버튼 텍스트: `'프로필 설정으로 이동'` → `'휴가 탭으로 이동'`
- 버튼 아이콘: `<Settings>` → `<Palmtree>` (lucide-react)
- 이동: 기존 `onNavigate(event)` → `useAppStore.getState().setView('vacation')` 호출
- 우클릭 퀵 편집에서도 동일 처리 (편집 탭 비활성화 + 안내 문구)
