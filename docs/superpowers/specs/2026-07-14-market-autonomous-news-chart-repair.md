# 모의 주식 자동 뉴스와 차트 신뢰성 설계

## 목표

관리자가 이벤트를 만들지 않아도 매일 한 건의 시장 뉴스가 자동으로 나타나고, 그 뉴스가 보이는 가격·차트·주문 체결 가격에 같은 방식으로 반영되게 한다. 차트에서는 거래량과 가격 봉이 어떤 조작 뒤에도 서로 다른 패널에 남아야 하며, 기간상 사용할 수 없는 시간봉을 선택할 수 없게 한다.

## 자동 뉴스 경계

- 뉴스는 KST 날짜마다 한 건을 결정론적으로 만든다. 날짜를 다시 계산해도 제목·대상 종목·시각·방향·영향이 같으므로 별도 스케줄러나 DB 저장이 필요 없다.
- 뉴스 공개 시각은 그날 KST 장중에 정하고, 카드와 오늘 움직인 이유에는 공개된 당일 뉴스만 보인다.
- 자동 이벤트 ID는 `auto:<kst-date>:<stock-id>`로 고정한다. Supabase의 `adminEvents`에는 절대 저장하거나 관리자 목록에 섞지 않는다.
- 자동 뉴스의 가격 효과는 뉴스 종료 뒤 짧게 감쇠해 0이 된다. 기존 관리자의 뉴스·충격·추세·거래정지 효과는 바꾸지 않는다.
- `shared/playgroundMarketPrice.mjs`가 자동 이벤트와 수동 이벤트를 합치는 유일한 경로가 된다. renderer와 Electron 주문 검증은 이미 이 wrapper를 쓰므로 같은 시세를 사용한다.

## 뉴스 표시

- `MarketQuoteContext`가 화면용 뉴스 목록과 종목별 동적 이유를 가진다.
- 홈은 context 뉴스, 종목 행과 상세는 context 이유, 상세의 최근 소식은 context 뉴스를 사용한다.
- 자동 뉴스가 없는 종목의 이유는 고정 seed 문구 대신 그날의 시장 흐름을 설명하는 동적 기본 문구를 보인다.

## 차트

- Lightweight Charts 가격 pane은 비어도 보존한다. 스타일 전환에서 선 시리즈를 제거한 순간 pane이 삭제되어 거래량이 가격 pane으로 이동하는 것을 막는다.
- 기간별 최소 시간봉 정책(오늘=1분, 1주=10분, 1개월=1시간, 6개월/전체=1일)은 1,500봉 제한과 성능 보호를 위해 유지한다.
- 선택 UI는 해당 기간에 실제로 쓸 수 없는 시간봉을 비활성화하고, 선택된 값이 자동으로 상향 조정될 수 있음을 설명한다.

## 검증 기준

1. 같은 KST 날짜와 수동 이벤트 입력이면 자동 뉴스·가격이 항상 동일하다.
2. 자동 뉴스는 시작 전에는 가격과 candle `newsIds`에 영향을 주지 않고, 종료 뒤에는 영향이 0으로 수렴한다.
3. renderer quote, 차트, Electron 주문 canonical quote가 같은 자동 이벤트를 사용한다.
4. 선↔캔들 전환 뒤에도 가격 pane은 0, 거래량 pane은 1이다.
5. 오늘 범위의 각 시간봉은 실제 집계 차이를 유지하고, 장기 범위에서는 불가능한 선택지가 비활성화된다.
