# B flow 간트 공간과 프로젝트 관리 — 승인된 구현 설계

작성일: 2026-09-05
상태: 사용자 선택 및 시안 승인 후 v1.111.0 구현. 구현 검증은 별도 기록을 참조하며 운영 DB 적용·배포는 아직 수행하지 않았다.

## 목적

현재 타임라인의 진행률 중심 화면을 실제 일정을 작성하고 조정하는 간트로 교체한다. 제작 프로젝트뿐 아니라 개인 계획, 신입 교육 커리큘럼을 작성하고 필요한 사람에게 공유한다. OmniPlan의 계층 편집과 직접 조작을 참고하고, 여러 프로젝트를 같은 날짜축에 표시한다.

## 사용자가 확정한 요구사항

- 프로젝트는 자유롭게 생성하며 기존 에피소드·씬을 선택적으로 연결한다.
- 간트 공간은 개인·팀 제작·교육 등 용도별로 만들고 여러 프로젝트를 담는다.
- 공간을 넘어서 접근 가능한 프로젝트를 선택해 하나의 간트에 표시한다.
- 공간 멤버·권한은 독립적으로 관리한다. 생성 시 기존 캘린더 멤버를 가져올 수 있지만 이후 변경은 연동하지 않는다.
- 프로젝트별 공개 범위·편집 권한을 설정할 수 있다.
- 작업마다 여러 작업자와 별도의 참석자를 지정한다.
- 진행률은 직접 입력하거나 연결된 씬에서 자동 계산하도록 선택한다. 그룹은 하위 작업을 종합한다.
- 작업마다 자동·수동 일정 계산을 선택한다. 자동 작업은 선행 일정에 따라 이동하고 수동 작업은 날짜를 유지하며 충돌을 표시한다.
- 날짜와 시간을 지정할 수 있다. 시간이 없으면 캘린더에 하루 종일 일정으로 표시한다.
- 자동 일정 계산은 기본적으로 주말·공휴일을 포함한다.
- 선택한 작업만 캘린더에 표시한다. 제목·날짜·메모는 양쪽에서 같은 작업에 반영한다.
- 캘린더 연결 전 공유 대상을 안내한다. 캘린더 사용자에게 제목·날짜·메모가 보이며 간트 상세는 간트 접근 권한이 필요하다.
- 연결된 작업의 편집에는 간트와 캘린더 양쪽의 편집 권한이 필요하다.
- 첫 구현은 간트 작성·편집·캘린더 연결에 집중한다. 작업 관계, 마일스톤, 실행 취소, 담당자 필터를 포함한다.
- 업무량 분석, 최초 계획 대비 분석, 프로젝트 복제·템플릿은 첫 구현에서 제외한다.

## 화면 제안

후속 시안 수정: 세로 날짜 격자를 숨기고 선·박스를 줄인다. 막대 호버에 전체 제목·기간·작업자·메모를 표시한다. 긴 작업명은 두 줄 표시와 이름 영역 폭 조절, 짧은 막대의 바깥 제목으로 읽기 쉽게 한다. 내 프로젝트/공유 프로젝트를 폴더 트리로 나누고 폴더 공유 설정을 제공한다. 개별 완료와 프로젝트 하위 일정 일괄 완료를 지원하고 완료 항목은 별도 보기로 모은다. 커서 날짜 중심 연속 휠 확대·축소와 Shift+휠 이동을 제공한다. 시안 Pretendard는 B flow 기존 글꼴 로드·선택 체계를 재사용한다.

앱의 타임라인 메뉴를 진입점으로 유지한다. 화면은 다음 영역으로 구성한다.

1. 접을 수 있는 공간·프로젝트 탐색 영역: 공간별 프로젝트 목록, 검색, 표시 체크박스, 전체 선택/해제, 이것만 보기.
2. 작업 목록과 날짜축이 행 단위로 맞물리는 간트: 프로젝트 → 그룹 → 작업 계층, 동일한 세로 스크롤, 고정 날짜 헤더, 조절 가능한 목록 폭.
3. 선택 시 열리는 상세 패널: 제목, 메모, 날짜·시간, 자동/수동, 작업자·참석자, 진행률, 선행 작업, 씬 연결, 캘린더 연결.

표시 체크는 개인의 보기 설정이다. 프로젝트의 공유 상태나 다른 사용자의 화면을 바꾸지 않는다. 프로젝트 토글은 현재 날짜·배율을 유지한다. 날짜 맞춤은 명시적인 버튼으로 실행한다. 처음에는 접근 가능한 진행 프로젝트를 요약 상태로 보여주고 이후 개인별 표시·접힘 상태를 복원하는 안을 제안한다.

프로젝트·그룹은 괄호형 요약 막대, 작업은 기간 막대, 마일스톤은 다이아몬드로 구분한다. 접힌 프로젝트에도 기간과 주요 마일스톤을 남긴다. 색상은 의미 있는 구분에 사용하고 B flow의 기존 테마와 한글 가독성을 유지한다. 상세 패널과 탐색 영역을 접어 편집 공간을 확보할 수 있어야 한다.

## 편집 동작 제안

- 빈 작업 행의 날짜 영역을 드래그해 작업을 생성한다. 소속 프로젝트는 생성 전에 명확해야 한다.
- 작업 막대 이동, 양끝 기간 조절, 작업 순서 변경, 들여쓰기/내어쓰기를 지원한다.
- 목록에서 제목을 직접 편집하고 키보드로 다음 작업을 추가한다.
- 여러 작업 선택과 실행 취소/다시 실행을 지원한다.
- 날짜 확대 단계는 월·주·일·시간을 제공한다. 확대 시 기준 날짜를 유지한다.
- 자동 작업을 직접 옮길 때는 수동으로 전환할지 명시적으로 안내한다. 자동 계산이 사용자 조작을 조용히 되돌리지 않는다.
- 기본 작업 관계는 선행 작업 종료 후 다음 작업 시작이다. 다른 관계 유형은 구현 계획에서 첫 범위를 명시한다.
- 마일스톤은 소요시간이 없는 시점이며 날짜만 또는 날짜·시간으로 설정할 수 있다.

## 데이터와 공유 설계 제안

프로젝트/작업을 기존 CalendarEvent의 부가 필드만으로 표현하지 않고 독립된 구조로 관리한다. 공간, 공간 멤버, 프로젝트, 프로젝트 접근 설정, 작업, 작업자·참석자, 선행 관계, 캘린더 연결을 구분한다.

공간의 권한을 프로젝트의 기본값으로 상속하고, 프로젝트별 제한을 추가하는 안을 제안한다. 공간보다 넓은 공개가 필요한 프로젝트는 별도 공간으로 분리하는 것으로 범위를 단순화한다. 이 상속 규칙은 사용자 검토 대상이다.

실제 앱의 저장은 Supabase를 정본으로 하고 Electron 경로에서 권한과 변경을 검증한다. 화면은 즉시 반영하고 실패하면 해당 변경만 롤백한다. 테스트 모드도 동일한 명령·권한·롤백 계약을 따른다.

캘린더 연결은 동일한 작업을 가리키는 연결 식별자로 관리한다. 기존 캘린더의 소스/캘린더/이벤트 식별 계약을 보존한다. 첫 연결 대상은 편집 가능한 B flow 캘린더로 한정하는 안을 제안한다. 외부 구독·휴가 일정은 편집 가능한 간트 작업으로 변환하지 않는다.

공유 필드 변경은 양쪽 편집 권한을 검사한다. 선행 작업 변경으로 연결된 후속 작업까지 이동하는 경우에도 영향받는 작업과 캘린더 권한을 검증한다. 날짜 변경과 캘린더 반영이 서로 어긋나는 부분 성공을 만들지 않도록 변경 단위를 설계한다.

캘린더에서 제거는 연결 해제로 처리하고 원본 작업은 유지하는 안을 제안한다. 간트 원본 삭제는 연결 일정도 제거하며 삭제 전에 영향 범위를 보여준다. 공유 대상 안내는 연결 시점의 현재 멤버를 기준으로 한다. 이후 캘린더 멤버 변경은 해당 캘린더의 공개 규칙을 따른다.

동시 편집 시 오래된 저장·취소가 다른 사람의 최신 변경을 덮지 않아야 한다. 실행 취소는 본인의 변경에 한정하며 이후 타인의 변경과 충돌하면 안내한다. 재연결·권한 변경 시 정본을 다시 읽고 더 이상 접근할 수 없는 프로젝트 및 상세 선택을 제거한다.

## 일정 계산 경계

자동 계산은 순환 관계를 거부하고, 수동 작업의 날짜를 보존하며, 위반된 선행 관계를 표시한다. 하위 작업 기간으로 그룹의 표시 범위를 계산한다. 주말·공휴일 포함이 기본이다. 시간 미지정 작업과 시간 지정 작업의 선후행 경계 및 하루 길이는 구현 계획에서 명확히 고정하고 행동 테스트로 검증한다.

그룹 진행률의 가중 방식은 구현 전 확정한다. 기본 제안은 말단 작업의 기간 가중 평균이며, 마일스톤은 기간 가중에서 제외한다. 연결된 씬 진행률은 기존 B flow 계산 규칙을 재사용한다.

## 기존 화면 정리

현재 src/views/CalendarView.tsx의 읽기 전용 간트를 신규 편집 화면으로 교체한다. 날짜축 없는 진행률과 히트맵은 신규 간트 기본 영역에서 제외하고 기존 현황 화면과 중복을 확인한 후 정리한다. 실제 씬·에피소드·캘린더 데이터는 보존한다. 컴포지팅 대시보드의 영상 타임라인은 별도 기능이므로 변경 대상이 아니다.

## 구현 단계 제안

1. 검토 가능한 화면 시안으로 다중 프로젝트 표시, 그룹 접기, 선택·상세 편집 동선을 확인한다.
2. 공간·프로젝트·작업·공유 구조와 테스트 모드 기반을 만든다.
3. 간트 직접 조작, 일정 관계, 자동 계산, 실행 취소를 연결한다.
4. 캘린더 양방향 연결과 씬 진행률 연결을 완성한다.
5. 기존 타임라인을 교체하고 회귀 검증 및 실제 브라우저 조작 검증을 수행한다.

각 단계는 최종 기능 완성을 위한 구현 분할이며 목업만으로 완료 처리하지 않는다. 운영 DB 변경, PR, 머지, 배포는 현재 승인 범위를 확인하여 별도로 수행한다.

## 검증 기준

- typecheck, 관련 테스트, build:vite 통과.
- 계층 이동·순환 방지·시간 경계·자동/수동 혼합·마일스톤·진행률 검증.
- 다중 사용자와 다중 창에서 권한 회수, 동시 수정, 실패 롤백, 재연결 검증.
- 캘린더 양방향 수정, 연결 해제, 삭제, 공유 권한 교집합, 후속 자동 이동 검증.
- preview 로그인 후 실제 간트 생성·드래그·기간 조절·토글·키보드 편집·캘린더 반영 확인.
- 기존 캘린더 소스 식별, 권한 회수 후 상세 제거, 연결 씬 이동 회귀 보존.
