# JBBJ 증권 초심자용 3화면 디자인 명세

## 1. 목적

JBBJ 증권은 주식에 익숙하지 않은 팀원이 포인트로 종목을 사고팔며 투자 흐름을 가볍게 익히는 기능이다. 토스증권의 쉬운 정보 위계와 일상적인 문장을 참고하되, B flow의 다크 테마와 JBBJ 포인트 시스템에 맞게 재구성한다.

이번 디자인의 핵심은 다음 세 질문에 빠르게 답하는 것이다.

1. 어떤 종목이 있고 오늘 어떻게 움직였는가?
2. 이 종목은 무엇이며 왜 움직였고, 나는 얼마를 사고팔 수 있는가?
3. 내 포인트와 투자 결과는 현재 어떤 상태인가?

- 현재 보유 종목, 평가손익, 확정손익 표시
- 초심자용 문구, 빈 상태, 잔액 부족 상태

### 제외

제외 항목은 좌측 메뉴나 링크로 진입점만 보여줄 수 있지만, 이번 3화면 구현 범위에는 포함하지 않는다.

## 3. 공통 디자인 원칙

### 3.1 초심자 우선

- 숫자보다 회사의 역할과 가격이 움직인 이유를 먼저 설명한다.
- `시장가`, `지정가`, `평가손익` 같은 용어를 첫 행동 전에 강요하지 않는다.
- 매수는 주 수량보다 `100P / 500P / 1,000P / 최대`를 먼저 선택하게 한다.
- 어려운 기능은 관련 영역 끝의 `원하는 가격에 주문하기` 또는 `수익분석에서 보기`로 단계적으로 공개한다.
- 같은 숫자나 설명을 여러 카드에서 반복하지 않는다.

### 3.2 토스증권에서 참고하는 것

- 중요한 금액을 크게, 보조 정보는 짧은 행으로 표시하는 위계
- 넓은 화면 안에서도 핵심 콘텐츠 폭을 제한하는 구성
- 왼쪽 이름, 오른쪽 값으로 반복되는 단순한 자산 행
- 한 화면의 핵심 행동 수를 제한하는 방식
- 복잡한 분석을 별도 화면으로 보내는 단계적 공개

토스 로고, 전용 폰트, 고유 아이콘, 브랜드 파란색, 화면 문구를 그대로 복제하지 않는다.

### 3.3 JBBJ 시각 체계

- 기본 배경: `#0D0F13` 계열
- 기본 표면: `#15181E` 계열
- 구분선: `#242832` 계열
- 본문 텍스트: `#F2F4F6`
- 보조 텍스트: `#9DA3AD`
- 주요 행동: 보라색 `#8173F2`
- 상승: 코랄 계열 + `▲`, `+` 표기
- 하락: 블루 계열 + `▼`, `-` 표기
- 본문은 시스템 한글 산세리프를 사용하고 숫자는 tabular numeral로 정렬한다.
- 다크모드를 기본으로 한다.

### 3.4 공통 내비게이션

상단 전역 내비게이션은 다음 항목을 유지한다.

- 시장 홈
- 종목 둘러보기
- 내 계좌
- 종목·뉴스 검색
- 사용자 계정 진입

시장 메인과 종목 상세는 같은 셸을 공유한다. 내 계좌는 동일한 상단 셸 아래에 계좌 전용 좌측 텍스트 메뉴를 추가한다.

### 3.5 시장 상태

- JBBJ 시장은 24시간 열려 있는 시장으로 표시한다.
- 가격은 시스템 기본 변동, 사용자 주문, 관리자 뉴스의 영향을 받을 수 있다.
- 설명할 만한 뉴스가 있으면 변동 이유를 한 줄로 보여준다.
- 특별한 뉴스가 없으면 `특별한 소식 없이 보통 범위에서 움직였어요`라고 표시한다.
- 이번 3화면은 실제 포인트를 사용하는 계좌를 기준으로 하며, 별도 연습계좌는 후속 범위로 남긴다.

## 4. 시장 메인 페이지

### 4.1 목표

사용자가 찜한 종목을 먼저 확인하고, 전체 시장도 놓치지 않게 한다. 한 화면에서 종목 이름, 현재가, 오늘 등락, 작은 그래프, 변동 이유를 이해할 수 있어야 한다.

### 4.2 정보 순서

1. 오늘 시장 요약
2. 찜한 주식
3. 오늘 가격에 영향을 준 소식
4. 모든 주식
5. 작은 초보 미션

찜한 주식과 모든 주식은 탭으로 서로 숨기지 않는다. 찜한 주식은 상단 카드, 모든 주식은 하단 목록으로 동시에 제공한다.

### 4.3 찜한 주식

최대 3개를 넓은 카드로 우선 표시한다.

- 종목명과 심볼
- 종목 성격
- 현재 가격
- `▲/▼`와 오늘 등락률
- 같은 시간축을 사용하는 오늘의 선 그래프
- 오늘 움직인 이유 한 줄
- `찜` 토글

찜이 0개면 비어 있는 공간 대신 초심자 추천 3개를 표시하고 각 카드에서 바로 찜할 수 있게 한다. 찜이 4개 이상이면 3개만 우선 표시하고 전체 개수와 `전체 보기` 진입점을 제공한다.

### 4.4 모든 주식

행 구조는 다음 순서를 사용한다.

`회사 | 성격 | 현재 가격 | 오늘 움직임 | 오늘 그래프 | 찜`

행 전체를 누르면 해당 종목 상세로 이동한다. 그래프의 세로 비율과 시간축은 종목 간 비교가 가능하도록 통일한다.

초기 종목은 다음 8개다.

- JBBJ
- YouTube
- 메타코미디
- Netflix
- Adobe
- Wacom
- Slack
- Google Drive

별도의 가상시장 경고 배너는 기본 화면에 노출하지 않는다.

### 4.5 변동 이유와 초보 미션

가격 관련 소식은 `이 소식 뒤 오늘 8.4% 올랐어요`처럼 원인과 결과를 한 문장으로 연결한다. 소식을 누르면 관련 종목 상세로 이동한다.

초보 미션은 한 번에 하나만 보여준다.

- 주식 하나 찜하기
- 가격이 움직인 이유 읽기
- 100P로 첫 주문 연습하기

미션을 완료하면 작은 진행 상태로 접혀 시장 탐색을 방해하지 않아야 한다.

## 5. 종목 상세 페이지

### 5.1 목표

트레이딩 도구가 아니라 종목 하나를 이해하고 작은 금액으로 행동하는 페이지로 만든다.

### 5.2 정보 순서

1. 회사 한 줄 설명
2. 현재 가격과 오늘의 변화
3. 오늘 움직인 이유
4. 가격 그래프
5. 내 보유 상태
6. 간편 주문
7. 최근 소식

우측 주문 영역을 유지해 토스증권 종목 화면의 익숙함을 살리되, 주문 위에는 `회사 확인 → 이유와 그래프 확인 → 부담 없는 포인트로 시작`이라는 짧은 순서를 둔다.

### 5.3 종목 요약

- 종목 심볼과 이름
- 회사가 하는 일을 설명하는 한 문장
- 현재 가격
- 오늘 가격 변화 금액과 비율
- `오늘 142P, 8.4% 올랐어요`처럼 풀어 쓴 문장
- 찜 토글

PER, PBR, 체결 강도 같은 전문 지표는 기본 화면에서 제거한다.

### 5.4 가격 그래프

- 기본은 선 그래프다.
- 기간은 `오늘 / 1주 / 1개월 / 전체`다.
- 기간을 바꾸면 선, 시작 가격, 이벤트 위치가 함께 변경된다.
- 왼쪽에는 기간 시작 가격, 오른쪽에는 현재 가격을 표시한다.
- 관리자 뉴스가 공개된 지점에는 이벤트 표시를 둔다.
- 상승·하락은 색뿐 아니라 기호와 문장으로도 구분한다.

봉차트, 거래량, 이동평균선, 호가창은 기본 화면에 표시하지 않는다.

### 5.5 내 보유 상태

보유 중이면 다음을 표시한다.

- 투자한 포인트
- 현재 가치
- 평가손익 금액과 비율
- 아직 팔지 않아 결과가 바뀔 수 있다는 짧은 설명

미보유 상태에서는 모든 값을 0으로 꾸미지 않고 `아직 보유하지 않음`과 `100P부터 시작할 수 있어요`를 보여준다.

### 5.6 간편 주문

#### 사기

- 기본 주문: 현재 가격으로 바로 사기
- 빠른 금액: `100P / 500P / 1,000P / 최대`
- 예상 구매 수량
- 구매 후 남는 예수금
- 금액이 포함된 단일 CTA

#### 팔기

- 빠른 비율: `25% / 50% / 전부 / 직접 입력`
- 예상 판매 수량
- 판매 후 받을 예수금
- 보유하지 않은 종목에서는 판매 CTA 비활성화

0P, 잔액 초과, 보유 가치 초과 주문은 CTA를 비활성화하고 버튼 문구로 이유를 알려준다.

`원하는 가격에 주문하기`를 누르면 고급 주문으로 진입한다. 여기에서만 지정가를 제공하며, 문구는 `원하는 가격이 되면 자동으로 사기`처럼 풀어서 설명한다.

## 6. 내 계좌 페이지

### 6.1 목표

계좌 첫 화면에서 다음 세 가지만 빠르게 읽게 한다.

1. 지금 투자 계좌에 얼마가 있는가?
2. 어떤 주식을 얼마나 보유하고 있는가?
3. 이번 달 투자 결과가 얼마인가?

### 6.2 레이아웃

- 상단 전역 내비게이션은 다른 시장 화면과 공유한다.
- 좌측에는 184px 안팎의 텍스트 메뉴를 둔다.
- 우측 영역이 넓어도 실제 자산 콘텐츠는 480~560px 단일 컬럼으로 제한한다.
- 대형 카드 그리드 대신 넓은 여백, 얇은 구분선, 반복 행을 사용한다.

좌측 메뉴:

- 자산
- 거래내역
- 주문내역
- 수익분석
- 계좌관리

이번 범위에서는 `자산`만 구현한다.

### 6.3 자산 화면

#### 계좌 헤더

- 계좌 선택기: `한솔님의 투자 계좌`
- 총자산: 예수금 + 현재 보유 주식 가치
- 포인트 지갑 잔액
- `넣기`, `빼기`

총자산은 한 번만 크게 표시하고 다른 카드에서 반복하지 않는다.

#### 쓸 수 있는 포인트

- 섹션 제목: `쓸 수 있는 포인트`
- 값: `내 포인트 예수금`
- 보조 설명: `주식을 바로 살 수 있는 포인트`

#### 현재 내 투자 현황

각 종목 행은 다음 정보만 기본 표시한다.

- 종목명
- 현재 가치
- 평가손익 금액과 비율

매수 금액, 평균 구매가, 비중, 회사 설명은 종목 상세에서 확인한다.

#### 내 투자 실적

- 이번 달 전체 결과
- 확정된 결과
- 보유 중 변화

자산 화면의 기본 기간은 `이번 달`이다. 기간별 차트와 `7일 / 1개월 / 전체` 상세 계산은 `수익분석` 화면으로 보낸다. 기본 자산 화면에는 차트를 표시하지 않는다.

### 6.4 포인트 넣기와 빼기

방향 전환이 있는 하나의 복잡한 모달 대신 동작을 분리한다.

#### 넣기

- 포인트 지갑 잔액
- 넣을 금액
- `1,000P / 5,000P / 전부`
- 이동 후 예수금
- `1,000P 넣기`

#### 빼기

- 꺼낼 수 있는 예수금
- 뺄 금액
- `1,000P / 5,000P / 전부`
- 이동 후 포인트 지갑
- `1,000P 빼기`

포인트 이동은 수수료가 없고 투자 실적에 포함하지 않는다. 투자 중인 금액은 바로 뺄 수 없으며 먼저 해당 주식을 팔아 예수금으로 바꿔야 한다.

## 7. 금액과 계산 규칙

- 포인트 지갑: 게임 및 작업 보상으로 얻은 포인트
- 예수금: 투자 계좌 안에서 아직 주식을 사지 않은 포인트
- 투자 계좌 총자산 = 예수금 + 보유 종목 현재 가치
- 평가손익 = 보유 종목 현재 가치 - 해당 종목 매수 원금
- 전체 투자 결과 = 확정손익 + 현재 평가손익
- 포인트 지갑과 투자 계좌 사이의 이동 금액은 수익으로 계산하지 않는다.
- 지갑 잔액은 투자 계좌 총자산에 포함하지 않는다.

예시 숫자:

- 포인트 지갑: 18,450P
- 예수금: 3,640P
- 보유 종목 현재 가치: 7,705P
- 투자 계좌 총자산: 11,345P
- 확정손익: +1,240P
- 평가손익: +205P
- 전체 투자 결과: +1,445P

## 8. 상태와 오류 처리

- 찜한 종목 없음: 추천 종목 3개와 찜 방법 표시
- 보유 종목 없음: 첫 투자 진입 CTA 표시
- 예수금 없음: `포인트 넣기`를 주문 영역의 다음 행동으로 제시
- 매수 잔액 초과: 주문 CTA 비활성화
- 매도 보유 가치 초과: 주문 CTA 비활성화
- 미보유 종목 판매 시도: `보유한 주식이 없어요`
- 포인트 이동 잔액 초과: 이동 CTA 비활성화와 입력 아래 오류 표시
- 가격·계좌 데이터 로딩: 기존 공간을 유지하는 스켈레톤 표시
- 저장 실패: UI를 이전 상태로 롤백하고 재시도 안내

데이터 변경은 B flow 원칙에 따라 로컬에 먼저 반영한 뒤 서버에 저장하고, 실패하면 이전 값으로 되돌리는 낙관적 업데이트를 사용한다.

## 9. 접근성

- 모든 아이콘 전용 버튼에 `aria-label`을 제공한다.
- 키보드 탭 순서는 화면의 시각 순서를 따른다.
- 포커스 링을 항상 표시한다.
- 모달은 배경을 비활성화하고 포커스를 모달 안에 가둔다.
- 모달을 닫으면 원래 열었던 버튼으로 포커스를 돌려준다.
- 오류와 완료 메시지는 `aria-live` 영역으로 알린다.
- 일반 텍스트는 최소 12px, 주요 본문은 14px 이상을 목표로 한다.
- 상승·하락은 색만으로 구분하지 않고 `+/-`, `▲/▼`, 상승·하락 문구를 함께 사용한다.
- `prefers-reduced-motion`에서 페이지 전환과 토스트 모션을 최소화한다.

## 10. 검증 기준

### 시장 메인

- 찜 토글 후 상단 찜 목록과 전체 목록이 함께 갱신된다.
- 종목 카드와 뉴스에서 올바른 종목 상세로 이동한다.
- 8개 종목의 가격, 등락, 그래프 방향이 서로 일치한다.

### 종목 상세

- 종목을 바꾸면 회사 설명, 가격, 그래프, 뉴스, 보유 상태가 모두 함께 변경된다.
- 기간 탭을 바꾸면 그래프와 시작 가격이 변경된다.
- 미보유 종목의 팔기 버튼은 비활성화된다.
- 매수·매도 금액이 가능 범위를 넘으면 주문할 수 없다.

### 내 계좌

- 넣기·빼기 후 지갑, 예수금, 총자산이 같은 금액만큼 일관되게 변경된다.
- 포인트 이동 후 확정손익과 평가손익은 변경되지 않는다.
- 총자산은 항상 `예수금 + 7,705P` 예시 산식과 일치한다.
- 계좌 첫 화면에는 그래프나 중복 계산 카드가 나타나지 않는다.

### 정적 검증

- `npm run typecheck`
- 관련 단위 테스트
- `npm run build:vite`
- 로그인 후 실제 Playground 진입 및 세 화면 수동 확인
