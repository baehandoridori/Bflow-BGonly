🔔 알림 탭 액션 버튼 — 4개 시안

"씬 보기 / 알림 읽음 / 삭제 버튼 추가" — 한솔 요청. 각 시안마다 어디에 어떻게 배치하느냐가 다름.

시안 1

👻 호버 시 액션 Fade-in

평소엔 깔끔하다가, 마우스 올리면 우측에 [씬 보기][읽음][삭제] 3 버튼이 부드럽게 등장. 가독성 우선.

🎯 본문 클릭 = 자동 + ⋯ 메뉴
