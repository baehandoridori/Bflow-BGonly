제가 보는 추천 결론

A안이 가장 낫습니다. 이미 있는 최근 작업 위젯의 흐름을 유지하면서도, 주석 이미지 변경과 메모 작성자를 사용자가 따로 찾아보지 않아도 됩니다.

구현 핵심

  • 주석 저장 시 activity_log에 “주석 이미지 업데이트” 활동을 새로 남깁니다.
  • 씬 상세 모달 메모 작성자는 별도 컬럼 추가보다 최신 memo_update 활동에서 먼저 가져오는 쪽이 낮은 위험입니다.
  • 옛날 메모처럼 작성자 기록이 없는 경우에는 작성자 줄을 숨기거나 “기존 메모”로 처리합니다.

결정할 것

  • A안 그대로 갈지, B안처럼 이미지 필터를 더 강하게 둘지 선택하면 됩니다.
  • 메모 작성자 위치는 “라벨 오른쪽”이 가장 눈에 잘 띄고 공간도 적게 씁니다.
  • 배프레임에도 같은 위젯을 새로 만들지 여부는 별도 작업으로 분리하는 편이 안전합니다.
