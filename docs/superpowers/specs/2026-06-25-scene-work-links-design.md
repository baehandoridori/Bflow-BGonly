# 씬 작업 링크 설계

> 작성일: 2026-06-25
> 대상: 카드 뷰, 시트 뷰, 씬 우클릭 메뉴, 씬 상세 모달 파일 탭
> 확인 목업: [docs/mockups/2026-06-25-scene-work-links-toggle.html](../../mockups/2026-06-25-scene-work-links-toggle.html)

## 1. 배경

BG/액팅 작업자는 실제 작업 폴더와 대표 작업 파일을 Bflow 밖에서 관리한다. 지금은 씬을 보고도 해당 작업 위치를 바로 열 수 없어서, 공유 드라이브나 개인 폴더를 다시 찾아야 한다.

이번 기능은 Bflow가 파일을 업로드하거나 관리하는 기능이 아니다. Bflow에는 **작업 폴더와 작업 파일의 경로만 연결**하고, 사용자는 카드/시트/파일 탭/우클릭 메뉴에서 그 연결 상태를 확인하고 바로 열 수 있게 한다.

## 2. 목표 / 비목표

**목표**

- 씬마다 BG/액팅 각각 `작업 폴더 1개 + 대표 파일 1개`를 연결한다.
- 카드 뷰와 시트 뷰에서 링크가 있는지 작은 아이콘 배지로 확인한다.
- 우클릭 메뉴에서 연결된 작업 폴더와 대표 파일을 바로 연다.
- 상세 모달의 파일 탭에서 연결, 변경, 해제를 관리한다.
- 경로 선택창과 경로 붙여넣기를 모두 지원한다.
- 개인 경로 또는 현재 PC에서 확인 안 되는 경로도 저장은 허용하되 경고한다.
- 나중에 대표 파일 외 `추가 파일`을 붙일 수 있도록 데이터 구조를 열어둔다.

**비목표**

- 실제 폴더/파일 생성, 삭제, 이름 변경은 하지 않는다.
- 파일 업로드, 버전 관리, 동기화, 권한 관리는 하지 않는다.
- 1차 범위에서는 추가 파일 UI를 만들지 않는다. 구조만 준비한다.
- 우클릭 메뉴에서 연결/수정 작업은 하지 않는다. 우클릭 메뉴는 빠른 열기 전용이다.

## 3. 최종 결정

| 항목 | 결정 |
|---|---|
| 저장 대상 | 파일 자체가 아니라 경로 문자열 |
| 공유 범위 | 팀 공용 링크 |
| 1차 링크 슬롯 | BG 폴더, BG 대표 파일, ACT 폴더, ACT 대표 파일 |
| 저장 방식 | 씬 기본 데이터와 분리된 `scene_work_links` 테이블 |
| 연결 방식 | 선택창으로 고르기 + 경로 붙여넣기 |
| 파일 선택창 | 확장자 제한 없음 |
| 폴더 열기 | 탐색기로 폴더 열기 |
| 파일 열기 | 기본 연결 프로그램으로 바로 열기 |
| 없는 경로 | 저장 허용, 파일 탭 경고, 열기 실패 토스트 |
| 개인 경로 | 저장 허용, 파일 탭 경고 |
| 링크 해제 | 확인창 필요, 실제 파일/폴더는 삭제하지 않음 |
| 링크 변경 | 확인창 없이 바로 변경 |
| 시트 배지 | 기본 켜짐, 사용자 개인 설정으로 저장 |
| 우클릭 메뉴 에피소드 표기 | `EP01` 같은 ID가 아니라 실제 에피소드 이름 |

## 4. 카드/시트 배지 UX

배지는 글자 없이 아이콘만 사용한다. 폴더는 폴더 아이콘, 파일은 파일 아이콘이다.

- BG: 보라 계열
- ACT: 기존 테마에 맞춘 붉은 계열
- 비어 있음: 회색
- 경로가 있지만 현재 PC에서 못 찾음: 색상은 유지하고 파일 탭에서 경고

회색은 “링크가 없음”만 뜻한다. 경로가 연결되어 있으면, 그 PC에서 못 열리더라도 색상은 들어온다.

### 4.1 카드 뷰

확정안은 목업 `A2`다.

- 카드 우하단에 작은 4칸 아이콘 클러스터를 둔다.
- 전체 뷰에서는 BG 2개가 왼쪽, ACT 2개가 오른쪽이다.
- 각 부서 안에서는 `폴더 → 파일` 순서다.
- BG 전용 뷰에서는 BG 폴더/파일만, ACT 전용 뷰에서는 ACT 폴더/파일만 보인다.
- 배지는 카드 내용을 읽는 데 방해되지 않게 작은 고정 크기로 둔다.

### 4.2 시트 뷰

확정안은 목업 `S1-A`다.

- 시트 컬럼 안에 배지를 넣지 않는다.
- 각 행의 왼쪽 바깥 거터에 표시한다.
- 전체 씬 뷰에서는 2층 구조다.
  - 위 줄: BG 폴더, BG 파일
  - 아래 줄: ACT 폴더, ACT 파일
- BG/ACT 상세 뷰에서는 1줄 2아이콘으로 접는다.
- 빠진 링크도 회색 아이콘으로 자리를 유지해 행마다 레이아웃이 흔들리지 않게 한다.

### 4.3 시트 배지 토글

시트의 배지가 여러 행에 반복되면 화면이 복잡해질 수 있으므로, 사용자가 끄고 켤 수 있게 한다.

- 위치: 시트 상단 도구줄 오른쪽
- 형태: `링크 배지` 텍스트 + 작은 스위치
- 기본값: 켜짐
- 저장: 사용자 개인 설정(`preferences.json`)
- 꺼짐 상태에서도 링크 데이터, 우클릭 메뉴, 파일 탭 기능은 그대로 유지된다.

## 5. 우클릭 메뉴 UX

우클릭 메뉴는 빠른 열기 전용이다.

전체 씬 뷰에서는 메뉴 안에 `배경`, `액팅` 구분선을 둔다.

```text
골목 야시장 추격 · A_014

배경
  작업 폴더 열기
  작업 파일 열기

액팅
  작업 폴더 열기
  작업 파일 열기
```

BG 전용 뷰에서는 배경 항목만, ACT 전용 뷰에서는 액팅 항목만 보인다.

링크가 없는 항목은 비활성 회색 상태로 표시한다. 보조 문구는 `파일 탭에서 연결`로 한다. 우클릭 메뉴 안에서는 새 경로를 연결하지 않는다.

메뉴에서 사용자에게 보이는 에피소드는 실제 에피소드 이름을 사용한다. `EP01` 같은 내부 ID는 노출하지 않는다.

## 6. 파일 탭 UX

상세 모달의 `파일` 탭에서 연결을 관리한다.

전체 뷰에서는 BG와 ACT 섹션을 모두 보여준다.

```text
BG
작업 폴더    [열기] [변경] [해제]
대표 파일    [열기] [변경] [해제]

ACT
작업 폴더    [열기] [변경] [해제]
대표 파일    [열기] [변경] [해제]
```

BG/ACT 상세 뷰에서는 해당 부서 섹션만 보여준다.

### 6.1 비어 있는 링크

링크가 없으면 다음처럼 보인다.

```text
작업 폴더    연결 안 됨    [연결]
대표 파일    연결 안 됨    [연결]
```

`연결` 버튼을 누르면 메뉴가 열린다.

- 선택창으로 고르기
- 경로 붙여넣기

### 6.2 연결된 링크

연결된 링크는 경로를 한 줄로 보여주고, 너무 길면 앞/중간을 줄인다. hover 또는 title로 전체 경로를 확인할 수 있게 한다.

버튼은 다음을 제공한다.

- `열기`
- `변경`
- `해제`

`변경`도 연결과 동일하게 선택창/붙여넣기를 모두 지원한다. 변경은 확인창 없이 바로 반영한다.

`해제`는 확인창을 띄운다.

```text
이 작업 링크를 해제할까요?
실제 파일이나 폴더는 삭제되지 않고, Bflow에 저장된 연결만 사라집니다.

[취소] [링크 해제]
```

### 6.3 경고 표시

경고는 파일 탭에서만 상세히 보여준다. 카드/시트 배지는 링크 존재 여부만 조용히 보여준다.

경고 종류:

- `개인 경로일 수 있음`: `C:\Users\...`처럼 다른 PC에서 열기 어려운 경로로 보일 때
- `이 PC에서 확인 안 됨`: 현재 PC에서 경로 존재 여부를 확인하지 못했을 때
- `폴더가 아닌 경로일 수 있음` 또는 `파일이 아닌 경로일 수 있음`: 붙여넣은 경로가 슬롯 종류와 맞지 않아 보일 때

모든 경고는 저장을 막지 않는다. 사용자가 팀 공유 드라이브를 다르게 매핑했을 수 있기 때문이다.

### 6.4 마지막 수정 정보

각 링크 줄에는 작게 마지막 수정 정보를 보여준다.

예:

```text
배한솔 · 오늘 14:20 수정
```

수정자는 Bflow 사용자 표시 이름을 우선 사용한다.

## 7. 경로 열기 / 선택 흐름

### 7.1 폴더

- 선택창: 폴더 선택창
- 열기: 탐색기로 폴더 열기
- 경로가 없거나 열 수 없음: 토스트 `이 PC에서 폴더를 찾을 수 없음`

### 7.2 파일

- 선택창: 파일 선택창
- 확장자 제한: 없음
- 열기: 기본 연결 프로그램으로 바로 열기
- 경로가 없거나 열 수 없음: 토스트 `이 PC에서 파일을 찾을 수 없음`

기존 `shellShowItem`처럼 파일 위치를 보여주는 동작이 아니라, 작업 파일 자체를 바로 연다.

## 8. 데이터 모델

씬 기본 데이터에 새 경로 칸을 직접 추가하지 않는다. 작업 링크 전용 테이블을 만든다.

테이블명은 `scene_work_links`로 한다.

핵심 구조:

```sql
CREATE TABLE IF NOT EXISTS scene_work_links (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  scene_uuid UUID NOT NULL REFERENCES scenes(id) ON DELETE CASCADE,
  department TEXT NOT NULL CHECK (department IN ('bg', 'acting')),
  link_kind TEXT NOT NULL CHECK (link_kind IN ('folder', 'primary_file', 'extra_file')),
  path TEXT NOT NULL,
  label TEXT,
  sort_order INTEGER NOT NULL DEFAULT 0,
  created_by TEXT,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_by TEXT,
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE UNIQUE INDEX IF NOT EXISTS uniq_scene_work_links_primary_slots
  ON scene_work_links(scene_uuid, department, link_kind)
  WHERE link_kind IN ('folder', 'primary_file');

CREATE INDEX IF NOT EXISTS idx_scene_work_links_scene
  ON scene_work_links(scene_uuid);
```

이 구조를 쓰면 1차 구현에서는 `folder`와 `primary_file`만 사용하고, 나중에 `extra_file`을 여러 개 추가할 수 있다.

경고 상태는 DB에 저장하지 않는다. `개인 경로`, `이 PC에서 확인 안 됨` 같은 상태는 사용자 PC 환경에 따라 달라지므로 앱에서 계산한다.

마이그레이션에는 RLS `allow_all` 정책, `updated_at` 자동 갱신 트리거, `ALTER PUBLICATION supabase_realtime ADD TABLE scene_work_links`를 포함한다. 앱의 Realtime 구독에도 `scene_work_links` 핸들러를 추가해 다른 사용자가 바꾼 링크가 카드/시트/파일 탭에 반영되게 한다.

## 9. 프론트엔드 구조

새 작업 링크 도메인을 씬 데이터와 분리한다.

구성:

- 타입: `SceneWorkLink`, `SceneWorkLinkKind`, `SceneWorkLinkDepartment`
- 서비스: `sceneWorkLinkService`
- 스토어: `useSceneWorkLinkStore`
- 배지 컴포넌트: `SceneWorkLinkBadges`
- 파일 탭 섹션: `SceneWorkLinksPanel`

스토어는 씬 UUID 목록 기준으로 링크를 읽고, `sceneUuid + department + linkKind`로 상태를 빠르게 찾을 수 있게 Map 형태를 제공한다.

업데이트는 기존 Bflow 패턴과 동일하게 처리한다.

1. 화면에 즉시 반영
2. Supabase 저장
3. 실패 시 롤백 + 토스트

## 10. Electron / IPC

필요한 Electron 기능:

- 폴더 선택창
- 파일 선택창
- 파일/폴더 바로 열기
- 현재 PC에서 경로 존재 확인

기존 `shellShowItem`은 파일을 바로 여는 목적과 다르므로 새 IPC를 추가한다.

동작:

- 파일 열기: `shell.openPath(filePath)`
- 폴더 열기: `shell.openPath(folderPath)`
- 실패 시 renderer에 실패 메시지를 반환하고 토스트 표시
- 선택창 취소는 오류가 아니라 `null` 결과로 처리

## 11. 개인 설정

시트 링크 배지 표시 여부는 팀 공용 데이터가 아니다. 사용자 개인 설정으로 저장한다.

필드:

```ts
sheetWorkLinkBadgesVisible?: boolean
```

기본값은 `true`다. 값이 없으면 켜짐으로 해석한다.

## 12. 테스트 기준

### 사용자 확인

1. 카드 전체 뷰에서 BG/ACT 폴더/파일 4개 배지가 글자 없이 보인다.
2. 시트 전체 뷰에서 왼쪽 바깥 거터에 BG/ACT 2층 배지가 보인다.
3. 시트 배지 토글을 끄면 시트 배지가 사라지고 새로고침 후에도 유지된다.
4. 파일 탭에서 폴더와 대표 파일을 선택창으로 연결할 수 있다.
5. 파일 탭에서 경로 붙여넣기로 연결할 수 있다.
6. 개인 경로를 저장하면 저장은 되지만 경고가 보인다.
7. 현재 PC에서 없는 경로도 저장되며, 열기 시 실패 토스트가 뜬다.
8. 연결된 파일은 기본 프로그램으로 바로 열린다.
9. 우클릭 메뉴에서 링크가 없는 항목은 회색 비활성으로 보인다.
10. 우클릭 메뉴의 에피소드 표기는 실제 에피소드 이름이다.
11. 링크 해제 시 확인창이 뜨고, 실제 파일/폴더는 삭제되지 않는다.

### 개발자 검증

1. `scene_work_links` 마이그레이션은 재실행해도 안전하다.
2. `folder`와 `primary_file`은 씬+부서별로 하나만 저장된다.
3. `extra_file`은 여러 개 저장할 수 있는 구조다.
4. 링크 변경 실패 시 낙관적 UI가 롤백된다.
5. Realtime으로 다른 사용자의 링크 변경이 반영된다.
6. 테스트 모드에서도 선택창 mock, 경로 붙여넣기, 배지 표시가 동작한다.
7. 라이트 모드와 다크 모드 모두에서 BG/ACT/회색 배지 대비가 유지된다.

## 13. 구현 순서 초안

이 문서는 구현 계획이 아니라 확정 UX/데이터 설계다. 실제 작업 순서는 별도 implementation plan에서 세분화한다.

추천 순서:

1. DB 마이그레이션과 작업 링크 타입/서비스/스토어 추가
2. Electron IPC: 선택창, 바로 열기, 경로 존재 확인 추가
3. 파일 탭 관리 UI 추가
4. 카드/시트 배지 UI 추가
5. 우클릭 메뉴 열기 항목 추가
6. 시트 배지 개인 설정 추가
7. 테스트 모드 mock과 회귀 테스트 추가
8. 실제 앱 preview에서 카드/시트/파일 탭/우클릭 메뉴 검증
