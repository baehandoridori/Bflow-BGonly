## 1. 배경과 목표

### 현재 상태
사이드바 "컴포지팅" 메뉴 = `src/views/CompositingView.tsx` (1366줄 단일 파일). 씬별로 그룹핑된 리비전 보드. 좌측 그룹 목록 + 우측 340px 슬라이드 디테일 패널 구조.

### 문제점 3가지
1. **v1.18.0 신표준 미적용** — RevisionItem이 여전히 우선순위 뱃지(긴급/높음/보통), 부서 칩, 프레임번호, "Rev.X" 형식을 표시. v1.18.0에서 등록 폼/카드/씬 모달은 정정했지만 컴포지팅 뷰는 누락
2. **검색·정렬 부재** — 다수 리비전 중 특정 항목 찾기 어려움. 정렬은 하드코딩(미해결+우선순위순)
3. **씬 모달 점프 부재** — 컴포지터가 씬 상세를 보려면 사이드바 → 씬 보드 → 에피소드/파트 선택 → 씬 클릭 단계를 거쳐야 함

### 목표
컴포지터가 보드 위에서 **빠르게 검색·필터링**하고, **필요시 씬 상세 모달로 즉시 점프**하며, **그룹화 관점을 자유롭게 바꿔가며** 컴포지팅 워크플로우를 진행.

## 2. 핵심 사용자 흐름

### 시나리오 A — 빠른 검색
1. 컴포지터가 컴포지팅 뷰 열기
2. 상단 검색창에 "색감" 입력 → 본문/씬 라벨/등록자에 매칭되는 카드만 표시
3. 매칭된 카드 클릭 → 우측 디테일 패널 슬라이드 인 (기존 동작)
4. 디테일 패널에서 댓글 확인/추가, 상태 변경

### 시나리오 B — 씬 상세 점프
1. 컴포지터가 씬 헤더의 ↗ 버튼 클릭 → 씬 모달 자동 열림 (리비전 탭으로)
2. 씬 모달에서 씬 전체 정보 + 다른 탭(상세/파일/히스토리) 확인
3. 모달 닫으면 컴포지팅 뷰 그대로 복귀

### 시나리오 C — 진행률별 보기
1. 상단 그룹화 토글 → "진행률별" 클릭
2. 화면이 칸반(대기/진행중/완료) 3컬럼으로 전환
3. 각 컬럼에 미니 카드들 표시. 카드 클릭 시 동일하게 디테일 패널 표시

## 3. UI 변경 요약

### 3-1. 헤더 (변경 없음)
"씬 타임라인" 타이틀 + 통계 + 모두 펼치기/접기 + 새 리비전 버튼. 기존 그대로.

### 3-2. 필터 바 (대폭 개선)

**Row 1 (신규)**:
- 검색 입력 (본문/씬 라벨/등록자 매칭)
- 정렬 드롭다운: 최신순(default) / 오래된순 / 씬 번호순 / 댓글 많은순

**Row 2 (기존 + 정리)**:
- 상태 세그먼트: 전체/대기/진행중/완료 (기존 유지)
- 에피소드 칩 필터 (기존 유지)
- "내 할 일만" 토글 (기존 유지)

### 3-3. 그룹화 토글 (신규)
필터 바 아래 우측에 토글:
- **씬별** (default, 기존 동작)
- **에피소드별** (EP 헤더 → 펼치면 그 EP의 씬들 nested → 각 씬 안에 미니 리비전 행들)
- **진행률별** (대기/진행중/완료 3컬럼 칸반)

### 3-4. 씬 헤더 (개선)
기존 구조 유지 + **우측 끝에 ↗ 씬 상세 모달 점프 버튼** 추가. 클릭 시 `bflow:open-scene-modal` CustomEvent 발행 (이미 존재하는 패턴 재사용).

### 3-5. 리비전 카드 (대폭 정정)

**제거** (v1.18.0 신표준):
- `PriorityBadge` (긴급/높음/보통)
- `StatusDots` (우선순위 색 도트)
- 부서 표시
- 프레임번호 mono 표시
- 카드 안 등록 폼의 우선순위 토글 + 프레임번호 input (이미 v1.18.0에서 RevisionPanel은 정정됨, 동일 적용)

**추가**:
- `re#` 라벨 (`revisionNoToLabel(n)` 헬퍼 사용)
- 좌측 썸네일 영역 64×40 (이미지 있으면 표시 + N개 더 있으면 "+N" 배지 / 없으면 dashed border placeholder, 카드 높이 일정 유지)
- 카드 호버 시 인라인 액션 (상태 ▾) 노출

**유지**:
- 좌측 컬러 사이드 바 (액센트 색 / 완료는 #00B894)
- 등록자 아바타 + 이름 + 시간
- 댓글 수 표시
- 상태 배지 (대기/진행중/완료 — STATUS_CONFIG)
- 카드 클릭 시 우측 디테일 패널 토글

### 3-6. 우측 디테일 패널 (변경 최소)
기존 340px 슬라이드 패널 그대로 유지. 단:
- 우선순위/부서/프레임 메타 표시 제거 (v1.18.0 일치)
- 상단에 "씬 상세 모달 열기" 링크 추가 (기존 패턴)

### 3-7. 그룹화 모드별 표시

**씬별** (default — 기존 SceneRow):
- 씬 헤더 → 펼치면 카드 목록 (기존)
- 카드 형태: 위 3-5 정정 적용

**에피소드별** (신규):
- EP 헤더 (EP01 + 에피소드 이름 + 미해결 카운트 + 씬·리비전 통계)
- 펼치면 그 EP의 씬들 nested. 각 씬은 미니 카드 (씬번호 + 메모 + 미해결 카운트 + ↗ 점프)
- 미니 씬 카드를 다시 펼치면 그 씬의 리비전 행들 (간소 — re#/상태/본문/시간만)

**진행률별** (신규):
- 3컬럼 칸반: 대기 / 진행중 / 완료
- 각 컬럼에 미니 리비전 카드 (씬 라벨 칩 + re# + 본문 일부 + 등록자/시간)
- 썸네일은 좌측 14×10 (작게)

## 6. 디자인 일관성

- **모든 강조 색은 CSS 변수** (`rgb(var(--color-accent) / N)`). 기존 hex 하드코딩 6곳도 같이 정리:
  - `#6C5CE7` (등록 버튼) → `bg-accent`
  - `#FDCB6E` (미해결 뱃지) → STATUS_CONFIG에서 가져옴 (이미 토큰)
  - `#74B9FF`, `#6B7280` (경로 색) → STATUS_CONFIG의 in_progress/resolved 사용 또는 토큰 추가
- **italic 금지** (메모/placeholder 색·opacity로만 약화)
- **호버 인터랙션**: `transition-colors duration-200`, transform 시프트 없음
- **테마 색 자동 반영**: 사이드 바, 강조선, 등록 버튼 모두 `--color-accent` 기반

## 9. 알려진 리스크

1. **분할 시 import 경로 변경 누락** — CompositingView를 import하는 외부 파일은 변경 없음 (default export 유지). 내부 SceneRow/DetailPanel/RevisionItem 등은 외부에서 import 안 됨.
2. **그룹화 토글 시 펼침 상태 보존** — `expandedScenes: Set<string>`이 그룹화 모드 변경에도 유지되어야 (씬별 ↔ 에피소드별 전환 시 같은 씬은 펼친 상태 유지)
3. **검색·정렬·그룹화 동시 적용 시 성능** — useMemo 캐싱 + 필터 우선순위 (검색 → 상태 → EP → 정렬 → 그룹화)
4. **씬 모달 점프 시 통합 모드/단일 부서 모드 분기** — 이미 v1.18.0의 NotificationPanel 라우팅에서 처리되는 패턴 재사용
