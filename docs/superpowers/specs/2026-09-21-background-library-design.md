# 배경 라이브러리 실제 반영

사용자가 확인한 background-workflow 목업을 실제 B flow에 반영한다. 장소별 파일 폴더를 유지하면서 도면, 공간, 카메라 시점, 배경 이미지, 시점 묶음, 에피소드 사용 기록을 별도로 관리한다.

- 사이드바 `배경` → 도면 탐색 / 배경 목록 / 시점 묶음 / 에피소드별 배경.
- 관리자는 임의 도면 트리와 공간을 만들고 배치한다. 사각형, 타원형, 자유 다각형, 이동, 크기, 회전, 잠금, 카메라 위치·방향, 도면 밑그림 이미지를 지원한다.
- 단일 클릭은 선택, 공간 더블클릭은 연결된 상세 도면으로 이동한다. 드래그는 이동으로 처리하고 도면별 선택·확대·위치를 복원한다. 상위 경로와 트리는 같은 이동 함수를 사용한다.
- 도면 아래에는 배경 이미지 그리드를 유지한다. 전체 범위는 현재 도면·하위 도면의 대표 장소/공간/카메라 연결, 공간 선택은 그 공간 장소·소속 카메라·연결 상세 도면, 카메라 선택은 명시 시점만 표시한다. 기호는 소속 공간, 공간 밖 기호는 도면 전체를 따른다. 무연결 도면은 관계없는 전체 라이브러리로 확장하지 않는다.
- 그리드에서 검색·구도·시간대를 좁히며 이미지를 열면 해당 변형의 상세가 도면 위에 열린다. 닫아도 도면·선택·필터가 유지된다. 오른쪽 속성은 접을 수 있고 이미지는 하단의 독립 스크롤 영역을 사용한다.
- 장소/파일 폴더는 원본 분류다. 도면의 공간을 지워도 장소, 배경, 에피소드 기록을 삭제하지 않는다. 사용 중인 원본 삭제는 참조 해제 전 차단한다.
- 카메라가 있는 장소, 화면에 보이는 장소, 관련 장소를 구분한다. 특수 클로즈업은 카메라 위치 없이 등록할 수 있다. 낮/밤은 변형, 이미지 수정본은 변형 안의 이력이다.
- 에피소드에는 장소와 구체적인 변형 ID들을 저장한다. 시점 묶음 적용은 ID들을 중복 없이 복사한다. 묶음 변경은 과거 에피소드를 변경하지 않는다. 에피소드+장소별 메모와 배경 상세의 역방향 사용 조회/변경을 제공한다.
- 실제 데이터는 서버 세션으로 검증하는 Supabase RPC가 정본이다. 현재 앱 관리자(role=admin)가 장소/도면/배경/묶음을 관리하고 로그인 사용자는 에피소드 연결을 편집한다. 권한은 main 및 DB에서 검증한다.
- 엔티티별 revision 비교로 충돌 시 덮어쓰지 않는다. 저장 실패 시 낙관 화면을 되돌리고 오류를 표시한다. 재시도 requestId는 멱등, 삭제한 ID를 재사용하지 않는다. 늦은 로그인 세션 응답을 폐기한다.
- 도면 노드와 이미지 변형 같은 복합 데이터는 각 엔티티의 JSON에 저장하되 전체 라이브러리를 한 덩어리로 덮어쓰지 않는다. DB도 타입·크기·참조·계층 순환을 검증한다.
- 테스트 모드도 같은 명령/검증/권한/충돌 계약을 사용하고 Web Locks + localStorage로 저장한다. 실제 서버가 준비되지 않았을 때 샘플 데이터로 성공한 것처럼 표시하지 않는다.
- 이번 작업은 구현·로컬 검증까지다. PR, 운영 DB 적용, 앱 배포는 명시 요청 시 진행한다.

검증: 단위 테스트(방향, 계층, 참조 보존, 묶음 복사, revision, 권한), 저장 실패/세션 경합 테스트, SQL 계약 및 가능한 로컬 DB 실행, typecheck, 관련 기존 테스트, build:vite, preview 로그인 이후 실제 화면 동작 확인.

## 작업파일과 이미지파일 연결

- 배경 상세의 변형마다 작업파일을 연결한다. 이미지 수정본마다 원본 이미지 경로를 연결하며 업로드한 공용 미리보기와 구분한다. 기존 수정본 작업파일 경로도 호환한다.
- 파일 선택·이미지 드롭·경로 직접 입력을 지원한다. PNG/JPG/WebP 원본을 읽어 미리보기를 등록하고 수동 이미지 갱신은 이전 수정본을 보존한다. 변형당 100개 한도는 업로드 전에 안내한다.
- 연결 해제는 원본 파일과 미리보기·이력을 보존한다. OS 연결 앱으로 파일을 열며 누락·접근 실패를 안내한다. 자동 감시와 폴더 스캔은 포함하지 않는다.
- 파일 읽기는 관리자·세션 검증과 용량·형식·이미지 디코드 제한을 적용한다. 원본은 수정하지 않고 투명도를 유지한 미리보기를 생성한다. 브라우저에서 실제 파일 경로를 얻지 못하면 경로 입력을 안내한다.

## 문과 사물 기호

- 도구 막대의 기호 팔레트에서 문·의자·테이블·침대·기타 사물만 선택하고 도면을 클릭해 놓는다. 책상·소파·수납장·화분은 기타 사물로 통합하며 이전 저장 데이터도 같은 기호와 분류로 표시하되 이름·위치·크기는 보존한다. 같은 기호 복제, 이동·회전·크기 조절·잠금 및 되돌리기를 지원한다.
- 문은 평면도 열림 원호와 방향 화살표를 표시한다. 경첩 좌우와 열리는 쪽을 각각 뒤집고 90도 단위 또는 자유 회전할 수 있다.
- 기호는 배경 시점과 별개의 `symbol` 도면 노드다. 공간 안에 놓으면 자동 연결하며 수동 변경도 가능하다. 공간 변형 시 연결 기호가 함께 움직이고 잠긴 기호는 유지한다. 공간 삭제 시 기호는 보존하고 연결만 해제한다.
- 기존 공간·카메라 데이터와 호환하며 공용 검증 및 SQL에서도 종류·문 방향·치수·같은 도면 공간 참조를 검증한다.


## 사용자 피드백 반영: 도면 생성과 연결 흐름

- 점 그리드를 제거하고 도면과 공간에 집중한다.
- 새 도면은 이름을 입력하면 생성·저장 후 편집으로 진입한다. 선택한 공간에서 내부 도면을 만들면 부모 공간과 연결까지 함께 저장하고 새 도면으로 들어간다.
- 기존 도면은 검색해서 연결할 수 있다. 다른 부모 아래의 도면은 하위 도면을 유지하며 새 위치로 이동하고, 이전 공간의 진입 연결은 함께 해제한다. 순환 경로는 선택에서 제외하고 서버에서도 거부한다.
- 도면 위치·밑그림은 도면 설정으로 모으고, 선택 공간의 좌표·크기·잠금과 배경 장소 연결은 접이식으로 표시한다. 폴더 트리는 접고 펼칠 수 있다.
- 생성·연결·위치 이동은 `save-maps` 명령 한 번으로 저장한다. 모든 도면의 revision을 검사한 뒤 전체 결과의 참조를 검증하며 하나라도 실패하면 전부 롤백한다.
