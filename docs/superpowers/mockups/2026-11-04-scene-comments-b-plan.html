요소지금B안
댓글 한 줄이름·시간 → 말풍선(내 글은 오른쪽·보라) → 호버 아이콘 + 상시 '답글' 알약아바타(30px 이니셜) + 이름·시간 한 줄 + 본문 13.5px. 전부 왼쪽. 말풍선 없음. 호버 시 우상단 툴바 한 줄(✅ 👍 👀 · 😊 · 답글 · ⋯)
답글본문 들여쓰기 블록에 전부 펼침 + 오른쪽 스레드 창에도 또본문에는 '답글 N개 · 아바타 · 마지막 시각 · 새 N' 한 줄. 누르면 오른쪽 스레드 창. 인라인 블록 제거
스레드 창메시지마다 '답글' 알약, 'X에게 답글' 라벨만 붙음원댓글 고정 + 답글 목록 + 입력창 하나. 답글 버튼 없음. 사람 지목은 툴바의 @ 로 입력창에 삽입. 헤더에 팔로우 토글
리테이크댓글이 최상위 말풍선으로 나열, 활동은 그림자 카드 + 버튼 3개리테이크 카드 하나가 루트(re# · 상태 · 요청·담당 · 설명 · 활동/댓글 수). 활동은 한 줄 시스템 행. 스레드 창에서 담당 완료·해결 버튼
안 읽음왼쪽 4px 보라 막대 + '새 댓글' 알약시각 옆 점 + 얇은 '새 댓글' 선. 막대 없음
필터'활동 감추기' · 're만' 텍스트 버튼탭: 전체 · 안 읽음 N · 리테이크 N · @나 N (밑줄 탭)
연속 댓글 · 날짜이름·시간 둘 다 사라짐, 날짜 구분 없음같은 사람 5분 안 연속은 아바타 자리 비우고 호버 시 시간. '11월 3일 월요일' / '오늘' 구분선
