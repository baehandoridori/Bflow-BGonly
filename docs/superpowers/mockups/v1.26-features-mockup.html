원인: addScene → IPC 호출은 끝났지만, 새 씬의 진짜 UUID가 로컬에 채워지기 전에 이미지 업로드 콜백이 옵티미스틱 씬(UUID 없음)을 참조

!
수정 실패: Error: 씬 UUID를 찾을 수 없음: EP03_E_ACT[31]

→ 씬은 추가됐지만 이미지는 빈 상태

● 수정 후
✓

→ addScene 시점에 UUID를 즉시 받아서 옵티미스틱 씬에 주입.
→ 또는 이미지 업로드 시 sceneId 기반으로 UUID 재해석 (인덱스 → sceneId 키로 변경).
→ 추가 토스트 없이 깔끔하게 완료.

버그 2 — 통합 뷰에서 씬 1개 선택 후 삭제 시 "2개 삭제" 표기
원인: bg:<key>와 act:<key>를 별개 UUID로 카운트. 사용자 시점에선 "한 씬"(머지드 카드 1장)임
● 현재 (혼란)
