# 에피소드별 배경 화면 통일

- [x] 캐릭터 `EpisodeAssetBoard`의 에피소드 선택 → 왼쪽 목록 → 오른쪽 상세, 검색 추가와 이미지 토글 패턴을 확인한다.
- [x] 장소 목록·대표 이미지·이 편 사용 썸네일·감독 노트로 화면을 재구성한다. 시점 묶음·저장 전 초안·실패 복구·기존 사용 기록을 유지한다.
- [x] 에피소드 표시명과 원본 상세 열기를 연결하고 작은 창/빈 목록을 정리한다.
- [x] 타입 검사, 관련 테스트, build:vite와 실제 프리뷰의 선택·수정·저장·상세 복귀·검색 추가·작은 창을 검증한다.

새 DB 구조나 배포는 포함하지 않는다. 캐릭터 전용 리깅 항목은 배경 화면에 복제하지 않는다. 기존 미배포 1.126.0 범위다.
