# 캘린더 입력 개선 및 외부 구독

사용자 승인: 앱 전용 날짜·시간 입력으로 교체하고 특정 캘린더를 아이폰·맥 기본 캘린더에서 구독한다. 기존 배포 요청 범위를 이어 간다.

1. 생성·빠른 편집·상세 편집에 공통 날짜 범위 선택, 24시간 직접 입력과 15분 제안, 기간 버튼을 적용한다. 잘못 입력한 값이 이전 값으로 저장되지 않도록 검증한다.
2. 소유자만 명시적으로 구독 주소를 발급·교체·중지한다. 기본 비공개, 256비트 주소와 서버 해시 저장, 세션 및 동시 변경 검증으로 보호한다.
3. 선택한 캘린더의 실제 일정과 간트 연결 일정을 RFC5545 읽기 전용 피드로 제공한다. 기존 링크를 중지하면 새 조회를 거절한다. 이미 외부 앱이 받은 데이터는 원격 삭제를 보장하지 않는다.
4. 테스트 모드에서 동일한 관리 동작을 제공하며 외부 기기로 구독되지 않는 로컬 미리보기임을 명시한다.
5. 입력·권한·세션·구독 파일·DB 테스트 및 브라우저 검증 후 운영 DB와 Edge Function을 적용한다. PR/머지, 정식 빌드, manifest 마지막 배포와 파일 해시 검증을 수행한다.

담당: calendar_tag_ui 공통 입력, calendar_sharing 편집창 통합, calendar_data DB/피드, root IPC/설정/프리뷰/통합·배포.

공식 사용 안내: https://support.apple.com/ko-kr/102301
