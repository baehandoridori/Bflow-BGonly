# 도면 탐색과 하단 이미지 그리드

사용자 요청: 도면 아래에 관련 이미지를 그리드로 표시하고 탐색 레이아웃을 다듬는다.

- [x] 도면/공간/카메라/기호 선택에 따른 이미지 범위를 공용 selector로 계산한다. 도면 전체는 하위 도면 연결도 포함하고 관계없는 전체 라이브러리로 확장하지 않는다.
- [x] 오른쪽 이미지 목록을 하단 그리드로 이동한다. 현재 범위·검색·구도·낮/밤 필터와 선택 해제를 제공한다. 도면 위치와 선택을 유지한 채 상세 모달을 연다.
- [x] 상단 여백과 도면/그리드 비율을 조정하고 속성 패널을 접을 수 있게 한다. 작은 창에서도 도면과 이미지가 함께 보이고 더 좁은 창에서는 세로로 탐색한다.
- [x] 범위 계산 회귀 검사, typecheck, 전체 build:vite, 실제 preview 선택/필터/상세 복귀 및 작은 창/라이트 모드 확인.

데이터 모델·DB migration·배포는 변경하지 않는다. 기존 편집 초안·기호·더블클릭 이동을 보존한다. 현재 미배포 v1.126.0 범위로 유지한다.
